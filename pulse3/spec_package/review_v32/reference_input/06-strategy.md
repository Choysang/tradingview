# 06 · 策略系统与优胜劣汰闭环

> 本卷回答：什么叫一个“策略”、怎么分类打标签与路由、怎么互相比较与晋升、怎么融合、怎么持续发现新策略、论文里的方法怎么接进来。
> 核心立场：平台不预设任何策略有效。每个策略都是一条被持续检验的假设；不删除任何策略，只改变它的状态与权限。

## 1. 一个登记库，一种规格

现状有三套互不映射的判定词汇、三处各自编号的策略资产（52 套产品战法、约 4,300 个因子表达式、75 条传统战法），研究结论进不了产品，产品结果写不回台账（01 卷）。

新系统里，下面这些东西全部用同一种规格登记在同一个库里，走同一条生命周期：

| 种类（`kind`） | 它做什么 | 产出 |
|---|---|---|
| `SELECTOR` 选股器 | 每个决策日给股票池打分或出名单 | 候选与分数 |
| `TACTIC` 操作策略 | 对一只已选中或已持有的股票，决定何时买、何时卖、做不做 T、挂不挂网格、每次多少 | 意图（07 卷） |
| `VETO` 否决器 | 判定某只股票现在不能买，或必须提示风险 | 否决与原因 |
| `OVERLAY` 叠加层 | 在组合层面调仓位：净值均线降仓、事件日不新开仓、波动目标 | 仓位系数 |
| `FEATURE` 特征与因子 | 一个可计算的数值列 | 面板列 |
| `ENSEMBLE` 融合器 | 把多个选股器合成一个榜单 | 融合分 |

传统战法、多因子、大模型选股、强化学习、技术形态买卖点、做 T、网格，在这里没有身份差别，只有 `kind`、标签和证据等级的差别。

## 2. StrategySpec

```text
StrategySpec
  # 身份
  strategy_id            稳定标识，例如 "sel.fusion.static40"
  version                规则、参数、退出、数据依赖的内容哈希；任何改动都产生新版本
  parent_ids             派生或合并自哪些规格
  kind                   见上表
  title, summary         给人看的名称与一句话说明

  # 假设与出处
  hypothesis             它为什么应该赚钱（或为什么应该规避），一段话
  source                 出处类型与链接：论文、研报、社区、内部实验、用户想法
  evidence_origin        ACADEMIC | BROKER | COMMUNITY_BACKTEST | FOLKLORE | INTERNAL

  # 可执行定义（全部是纯函数或声明）
  universe               股票池规则（板别、上市天数、价格、流动性、风险警示）
  inputs                 依赖的数据集与列；运行时据此判断数据是否齐备
  signal_ref             信号函数或表达式
  entry, exits, sizing   入场规则、退出规则、仓位规则（选股器可以只给默认值）
  hold_sessions, exit_at 持有期（07 卷的统一写法）
  params                 参数及其允许范围

  # 分类标签（第 3 节）
  tags

  # 预注册
  prereg                 判定标准、时段、最小样本、登记时刻（必须早于第一次看结果）
  trial_family           所属试验家族与该家族累计试验数

  # 状态与证据
  status                 生命周期状态（第 5 节）
  status_history         每次迁移：时刻、依据、证据引用；只追加
  ledger_refs            对应的实验记录
  revive_when            休眠后重新启用的条件，写成可计算的规则
```

不变量：

1. 规格里的每个规则都必须是可执行的，不允许自由文本充当规则。
2. 规格一经登记不可修改；修改即新版本，旧版本的记录保留。
3. 判定只在固定时段上做，用统一的基准与统计方法（07 卷第 6、7 节）。
4. 实盘在用的选择逻辑与战绩回放的选择逻辑是同一个函数（现状不是，01 卷 #28）。
5. 进入推荐榜权重的策略必须有前向记录；例外只有“旧制前向”一类（第 9 节）。

## 3. 分类与标签

### 3.1 策略标签

| 标签 | 取值 |
|---|---|
| `layer` | 选股、个股操作、组合配置 |
| `family` | 情绪题材、技术形态、因子、事件、轮动、机器学习、大模型、执行与仓位 |
| `plane` | 它主要依赖哪个面：消息、情绪、资金、技术、基本面、宏观（可多选） |
| `horizon` | 日内、短线（1–5 日）、波段（5–40 日）、长线（40 日以上） |
| `style` | 价值、质量、成长、动量、反转、低风险、规模、流动性、彩票回避、其他 |
| `method` | 规则、因子排序、树模型、深度模型、强化学习、大模型、混合 |
| `exec_mode` | 盘后决策次日开盘、竞价、盘中触发、尾盘 |
| `data_needs` | 日线、分钟、快照、基本面、一致预期、龙虎榜、公告文本、新闻、社区 |
| `regime_fit` | 它声称适用的市场状态（五轴上的取值），由回测与前向统计填写，不由作者主观填写 |
| `capacity` | 微、小、中、大 |
| `cost_sensitivity` | 低、中、高（由换手与单笔期望算出） |
| `evidence_origin` | 学术、券商、社区回测、经验之谈、内部 |
| `decay` | 稳定、衰减中、拥挤、未知（由滚动前向指标与公开因子库的相关性算出） |

### 3.2 股票标签

每只股票在每个交易日有一组时点正确的标签，存放在特征面板与参考数据里：

| 标签 | 来源 |
|---|---|
| 板别、行业（申万三级）、所属题材及其角色（龙头、中军、跟风、补涨） | 参考数据与 05 卷第 7 节 |
| 市值分层、风格暴露（连续值） | 特征面板 |
| 股性：近一年涨停次数、封板成功率、最高连板、波动分位 | 特征面板 |
| 约束：风险警示、次新、停牌、解禁临近、被立案、退市风险、被重点监控 | 参考数据与事件 |
| 当前事件标签与席位风险标记 | 消息与资金信号 |
| 热度状态：相对自身基线的 z 分数 | 情绪信号 |

### 3.3 路由

路由是确定性的规则，不是学出来的模型。一次请求（“今天的短线榜”“半导体板块的推荐”“这只持仓的卖出计划”）按下面的顺序筛出适用的策略子集：

1. `kind` 与 `layer` 匹配请求类型。
2. `horizon`、`universe` 与请求匹配。
3. `inputs` 声明的数据在当前快照里齐备且新鲜；不齐备的策略本次不运行，并在结果里写明“因何缺席”。
4. `status` 决定权限：能否进入权重、只能展示、还是只记录。
5. 股票侧的约束标签先于任何打分生效（否决器）。
6. `regime_fit` 只作为展示与事后归因的维度，不用于自动启停。依据：按市场状态或类比日自动选择策略的做法在本项目里全部失败（E006、E020、E042）；学习型的专家混合路由只有未经同行评审的预印本，没有 A 股证据（09 卷）。

## 4. 策略表达方式

| 形式 | 用于 | 说明 |
|---|---|---|
| 因子表达式 | `FEATURE` 与因子类选股器 | 一种受限的表达式语言（算子、窗口、截面排名）；可以做语法树层面的去重与复杂度度量 |
| 结构化规则 | 事件类、形态类、否决器、操作策略 | 条件、阈值、时序关系写成结构化数据，由确定性代码编译执行 |
| 纯函数 | 无法用前两种表达的 | 输入是 `DataView`，输出是打分或意图；不得做 IO |
| 外部模型产物 | 树模型、深度模型、大模型判断 | 以“打分表”的形式进入：模型在别处运行，结果登记成数据集；平台只认登记后的分数 |

通达信公式、TradingView 脚本、聚宽策略等外部写法只作为**导入方言**：导入时翻译成上面的形式，并附行为等价测试。

**因子表达式语言（第一版）**

| 类别 | 内容 |
|---|---|
| 基础列 | `open`、`high`、`low`、`close`（均为复权价）、`volume`、`amount`、`ret`（日收益）、`turnover`、`float_mv`，以及特征面板里登记的其他列 |
| 逐元素 | 四则运算、`abs`、`log`、`sign`、`power`、`max`、`min`、条件选择 |
| 时序（按股票） | `delay(x,n)`、`delta(x,n)`、`ts_mean`、`ts_std`、`ts_var`、`ts_sum`、`ts_max`、`ts_min`、`ts_rank`、`ts_argmax`、`ts_argmin`、`ts_corr(x,y,n)`、`ts_cov`、`ema`、`wma`、`ts_slope` |
| 截面（按交易日） | `cs_rank`（百分位，0–1）、`cs_zscore`、`cs_demean`，可按行业分组 |
| 语义 | 窗口不满时输出空；除以 0 输出空；空值按算子传播；截面算子只在当日可交易池内计算 |

窗口长度只能取登记过的集合。表达式的规范化形式（去掉无关的括号与交换律差异）用于去重与复杂度度量。旧系统冻结打分器所用的表达式由迁移车道导出，并附每个算子与每个因子在固定样本面板上的输入输出作为标准样例；新求值器以通过这些样例为准。

## 5. 生命周期

```text
提出 PROPOSED ─▶ 已登记 REGISTERED ─▶ 候选 CANDIDATE ─▶ 影子 SHADOW ─▶ 试用 PROBATION ─▶ 正式 LIVE
                      │                    │                │               │              │
                      └────────────────────┴───── 已证伪 REFUTED ◀──────────┴──────────────┘
                                           任何状态 ⇄ 休眠 DORMANT
                 （另有只读状态：旧制前向 LEGACY_FORWARD，仅用于从旧系统导入的冻结账本）
```

| 状态 | 含义 | 权限 |
|---|---|---|
| 提出 | 有想法或线索，规格未写完 | 无 |
| 已登记 | 规格完整、预注册完成、无前视测试通过 | 可回测 |
| 候选 | 通过回测门槛 | 可以冻结版本并进入影子 |
| 影子 | 版本冻结，纸面账户开立，前向记录中 | 界面可见，标“检验中”；权重为 0 |
| 试用 | 通过影子门槛 | 进入融合，权重有上限 |
| 正式 | 通过长期前向 | 进入融合，权重上限放开 |
| 休眠 | 证据转弱或适用条件不成立 | 权重为 0，保留监控；满足 `revive_when` 时回到影子 |
| 已证伪 | 预注册的判定明确不成立 | 不参与融合；作为同类新想法的拒绝先验；其反向可登记为否决器候选 |

各级的通过条件在 07 卷第 8 节。**不删除**是用户定下的规则，原样继承。

### 5.1 状态、界面标签与权限的对应

这张表是全平台唯一的权限定义。信号的 `usage`（05 卷第 1 节）、界面的证据标签（总纲第 5 节）、融合的权重都从它读取。

| 状态 | 界面标签 | `evidence_tier` | 允许的 `usage` | 融合权重 |
|---|---|---|---|---|
| 提出、已登记 | 未检验 | `UNTESTED` | DISPLAY | 0 |
| 候选 | 检验中（回测通过，前向未开始） | `TESTING` | DISPLAY、ALERT、RISK、VETO、POSITION（只减） | 0 |
| 影子 | 检验中 | `TESTING` | 同上 | 0 |
| 旧制前向 | 检验中（旧制记录） | `TESTING` | 同上，另加 RANK（过渡期例外，见下） | 过渡期主干 |
| 试用 | 已验证 | `VERIFIED` | 全部 | 单个策略不超过所在榜单权重的 10% |
| 正式 | 已验证 | `VERIFIED` | 全部 | 不设上限 |
| 休眠 | 沿用休眠前的标签，加“休眠” | 沿用 | DISPLAY | 0 |
| 已证伪 | 已证伪 | `REFUTED` | DISPLAY | 0 |

三条说明：

1. **只减不增的用途门槛更低。** 否决（VETO）、风险标记（RISK）、告警（ALERT）、把仓位系数调到 1 以下（POSITION 只减），只会让系统少买、少持或多提醒，出错的代价是错过机会而不是亏损。所以它们在“候选”（通过回测门槛）时即可生效。能让某只股票排得更靠前的 RANK 用途，以及把仓位系数调到 1 以上，必须有前向证据（试用及以上）。
2. **旧制前向的例外。** 从旧系统导入的冻结融合分是目前唯一有冻结后前向记录的排序器，过渡期内允许它承担排序主干。例外在以下任一条件满足时结束：同一榜单里有策略达到“试用”；或它自己按新门槛完成评估并得到正常状态。
3. **可交易池约束不是策略。** 停牌、一字板买不到、风险警示、上市未满规定天数、收盘价低于 2 元、成交额过低，是制度与可交易性的事实。它们写在内核的股票池规则里，对所有策略生效，不走生命周期，界面上标为“规则”。

## 6. 联赛

### 6.1 设计取舍

用户的设想是“像瑞士轮那样让策略互相比较、晋升，也可以合并”。瑞士轮的精神是：不因一场失利淘汰、每轮与实力相近者比较、多轮之后排名收敛。这些都保留。但有三处必须改，否则会重蹈台账里已经证伪的做法：

| 朴素做法 | 问题 | 本设计 |
|---|---|---|
| 按一轮的收益高低记胜负 | 同一市场同一时期的策略收益高度相关，单轮高低大多是噪声（09 卷） | 胜负由“逐日配对差的块自助检验”判定，分不出高下就是平局 |
| 按近期名次分配资金 | 本项目实测：相邻月的名次相关只有 +0.11，上月冠军次月平均排在第 37 百分位；追冠军在所有时段为负（E005） | 名次只决定**状态**，不直接决定**权重**；权重看长窗口证据并做收缩 |
| 所有策略混在一起比 | 短线情绪策略与长线因子策略不可比 | 先分组再比 |
| 在高度相关的策略之间切换 | 本项目实测：切换不如固定组合（经验卡） | 高相关的策略聚成一簇，融合时一簇只算一票 |

### 6.2 规则

- **分区**：`kind × horizon × family`。只有同一分区内的策略互相比较。这就是“先归类、再路由”。
- **参赛资格**：状态为影子及以上，且在统一仿真里有纸面账户。
- **赛季与轮次**：一个季度为一个赛季，每 20 个交易日为一轮（可配置）。
- **每轮的比较对象**：
  1. 07 卷第 6.1 节的四个“必须打败”的基准：现金、风格匹配基准、同日同池随机对照、防守基线。
  2. 分区内名次相邻的若干个对手（瑞士轮式配对，避免两两全比）。
- **一场比较的结果**：取双方自入赛以来的全部前向日收益，计算逐日配对差，做块自助检验。显著更好记胜（1 分），显著更差记负（0 分），分不出记平（0.5 分）。
- **分层**：每轮结束对每个分区做模型置信集检验，得到“统计上无法区分的最优集”。在最优集内且打败四个基准的，具备晋升资格；被排除在最优集之外且输给现金的，具备降级资格。
- **迟滞**：晋升与降级都要求连续两轮具备资格，防止来回抖动。
- **与晋升门槛的关系**：从影子到试用、从试用到正式，必须**同时**满足 07 卷第 8 节的条件与本节的“连续两轮具备晋升资格”。联赛不负责影子之前的各级。
- **现金是参赛者**：一个分区里如果没有任何策略打败现金，这个分区的结论就是“观望”。这条规则沿用现有产品的做法。
- **积分的用途**：展示与同层内排序。它不是权重。

### 6.3 合并与同质

- 两个策略的日收益相关高于 0.8 且配对差分不出高下，标记为“同质”。融合时同质簇合计只占一个投票者的权重。
- 用户或智能体可以把两个策略合并成一个新规格（`parent_ids` 指向双方），新规格从“已登记”重新走流程。合并不是把两个分数相加后直接上线。
- 被证伪策略的“糟粕”也有去处：若其反向（规避它选中的股票）在预注册检验下成立，就登记为否决器。已有两个先例：超涨不买、散户集中席位共买回避（01 卷第 7 节）。

### 6.4 试验预算

每个分区每个赛季有“新增试验数”的预算。每多登记一批候选，该家族的显著性门槛按累计试验数相应提高（07 卷第 7 节）。依据：在同一段数据上测得越多，靠运气通过的就越多；本项目已有在 490 套策略里“发现”噪声的实例（闭环评审）。

## 7. 融合：推荐榜是怎么来的

```text
可交易池 ──否决器（硬约束）──▶ 候选池
候选池 ──各选股器打分──▶ 分位数 ──按簇去重、按权重合成──▶ 融合分
融合分 ──风险惩罚与标签──▶ 排序 ──叠加层（仓位系数）──▶ 推荐榜（按周期分榜）+ 回避榜
```

规则：

1. **按周期分榜**：短线、波段、长线各自融合，不把情绪分与技术分平均成一个数。依据是用户 2026-11-01 的修正意见与台账。
2. **权重**：扩张窗口上的长期证据（信息系数或风格匹配超额），向分区均值收缩；试用状态的权重有上限。不使用“近 N 日最优”的动态权重。依据：动态权重在转折点追的是刚失效的因子（E011、E014）。
3. **归一**：融合分 = Σ（权重 × 信号分位）÷ **全部**具备权重的投票者的权重和；当天没选某只股票的策略记 0（现状实现与此相反，01 卷 #30）。
4. **否决先于打分**：风险警示、停牌、一字板买不到、低于 2 元、解禁临近、已确认的利空事件、散户集中席位共买、过热。
5. **叠加层只改仓位**：净值均线降仓是第一个叠加层（E036、E040）；议息反应日不新开仓是候选（E083）。
6. **没有手写的“技术分、情绪分”混入总分**。这些信息要么是登记过的特征，要么是登记过的策略，一律走同一套门槛（现状总分的一半来自未经检验的手写子分，01 卷 #29）。
7. **榜单不可变**：每期榜单带快照号发布后不再修改；数据修订产生新版本并保留旧版本。
8. **回避榜与推荐榜并列**。依据：冻结分数的价值主要在避开最差的股票（E071：只买前 30% 不比随机好，剔除后 20% 才比随机好）。大模型打了“回避”标签的股票在已记录的卡片上 5 日超额为 −1.2 到 −1.7，台账的评价是“可能有用，需要新数据检验”（E064），所以它以“检验中”的标签出现在回避榜上，不参与排序。

每只上榜股票附一张解释卡：哪些策略投了票及各自的证据等级、四个面的信号、风险标记、建议的入场方式、退出计划、对应的操作策略、它依赖的数据快照。

## 8. 个股操作策略

进入个股之后的买卖点、持有计划、做 T、网格，统一建模为**操作策略**：一个只读行情与持仓状态、只输出意图的状态机。

### 8.1 能力清单

| 能力 | 内容 |

| 退出规则 | 固定持有、止损、分批止盈、均线或吊灯移动止损、封单衰减、炸板、跌破分时均价、情绪退潮、逻辑失效（持仓出现已确认利空） |

## 10. 发现闭环：持续搜寻、形式化、检验、入库

```text
来源 ─抓取─▶ 线索 ─去重─▶ 假设卡 ─形式化─▶ 规格草稿（提出）─自动测试─▶ 预注册（已登记）
   ─统一仿真回测─▶ 判定 ─▶ 候选 / 已证伪 ─▶ 影子前向 ─▶ 联赛 ─▶ 权重或休眠
                                   └────────── 结果写回台账与失败经验库 ──────────┘
```

| 环节 | 做法 |
|---|---|
| 来源 | 论文预印本库的金融与机器学习分类、指定的开源仓库、策略数据库与研究博客、券商研报标题、社区热帖标题、用户与智能体的想法。清单见 09 卷附表 D。需要登录或版权不明的站点只存标题与链接 |
| 节奏 | 每日：论文与仓库更新；每周：博客、研报标题、社区；每月：整库重扫与来源有效性检查 |
| 去重 | 三层：链接与标题哈希；向量相似度聚到已有策略家族；规格层的等价性（表达式语法树相似度，或在同一数据切片上信号高度相关） |
| 假设卡 | 大模型从原文抽取结构化卡片：假设、规则、所需数据、声称的效果、出处、证据级别。只抽取，不评价好坏 |
| 排队 | 按“先验证据强度、所需数据是否已有、与现有库的新颖度、成本敏感度”排序。分数只用于排队，不用于通过 |
| 形式化 | 把假设卡写成规格草稿。大模型产出的是结构化规格，由确定性代码编译；不让大模型直接写回测。每个规格附带单元测试与标准样例，校验“代码做的事与规格说的事一致”。依据：2025–2026 年的多个基准都指出大模型写的策略代码“能跑但逻辑不对”是主要风险（09 卷） |
| 自动测试 | 无前视截断测试、可交易性掩码、数据依赖检查 |
| 检验 | 统一仿真 + 07 卷的门槛；所属家族的试验数加一 |
| 写回 | 无论成败都写入台账；失败的写明当时的市场环境与值得重试的条件；规格哈希进入失败经验库，新线索命中同族时降级或跳过 |

研究自动化的四条约束（来自 2025–2026 年因子挖掘文献里共同有效的做法，09 卷）：

1. **原创性**：新表达式与库内表达式的语法树相似度过高则拒绝。
2. **复杂度惩罚**：表达式越长、参数越多，门槛越高。
3. **固定沙盒与封存样本**：挖掘只能看到指定时段；另留一段只在最终判定时打开一次。
4. **失败记忆**：挖掘器在生成前先检索失败经验库。

## 11. 论文方法的接入方式

调研检索了 2025–2026 年金融期刊、工作论文与计算机会议里的一百余条相关文献线索，本规格实际引用并登记的约 50 条（09 卷第 3 节）。其中 2026 年的条目多数是未经同行评审的预印本，结果多为作者自报。按“证据强度与可落地性”分三种接法：

| 方法或发现 | 接法 | 理由 |
|---|---|---|
| 可交易性掩码（涨跌停造成的不可成交价不能喂给因子评估） | 内置 | 文献报告忽略它会使信息系数虚高约 18%；与本项目“涨停买不到”的经验一致 |
| 大模型前视偏差的检验（记忆化检验、按截止日切分） | 内置 | 多篇文献证明泄漏显著放大表观预测力 |
| 前向归因：把收益分解为市场、风格、选股三部分 | 内置 | 泄漏受控的 A 股评测显示大模型收益主要来自市场与风格暴露 |
| 长周期、宽截面、对简单防守基线的比较 | 内置为门槛 | 长周期评测里复杂方法的优势大幅缩水 |
| 收缩夏普、过拟合概率、清洗与禁运的组合交叉验证、模型置信集 | 内置统计 | 标准方法，有成熟开源实现 |
| 新闻新颖度与重组旧闻识别 | 内置字段 | 近一半文章内容陈旧，重组旧闻引发反转 |
| 关注度之后反转、散户小账户反向预测 | 反向过滤类信号 | 多项中文市场研究一致 |
| 隔夜与日内收益拆分、彩票型股票回避 | 特征与否决器 | A 股隔夜收益显著为负，彩票型异象主要来自隔夜 |
| 因子准入门槛 t ≥ 3 并扣费 | 内置门槛 | 中国 469 个异象里约 84%–87% 复现失败 |
| 大模型作为“研究员”产出可执行因子，由确定性代码评估 | 架构原则 | 大模型逐日决策的运行间方差大、动作翻转 |
| 研究自动化闭环（假设、实现、回测、反馈）及其约束 | 研究流程 | 思想可借鉴；各论文的收益数字均为作者自报，不采信 |
| 不依赖回测的因子预筛 | 候选工具 | 可省算力；需先在本数据上验证与完整回测的一致性 |
| 按时间截断训练的语言模型 | 候选工具 | 可做历史对照；目前没有中文 A 股专用版本 |
| K 线基础模型与通用时序基础模型 | 仅作特征候选 | 现成模型在金融收益上零样本不可靠；官方回测不含成本；先检验其输出的信息系数与稳定性 |
| 股票关系图特征（行业、题材、共同持有的邻域） | 特征候选 | 成本低；相关论文的结果均为自报 |
| 增量适应分布漂移的训练流程 | 候选流程 | 对应本项目“学习类方法在风格切换后失效”的问题 |
| 强化学习 | 只作仓位或执行层的候选，要求多随机种子报告 | 稳健性基准显示多数算法换种子结果就变；本项目离线强化学习择时失败 |
| 波动率目标仓位 | 叠加层候选 | 有支持也有样本外失效的批评；只在组合层使用并扣成本 |
| 分数凯利 | 仓位规则选项，上限 0.5 | 全凯利在估计误差下长期增长为零 |
| 多智能体辩论式交易 | 不采用为决策者 | 没有可靠的增益证据；公开比赛里多数模型亏损并过度交易 |
| 大模型看图判断 K 线 | 不采用 | 证据弱且不针对 A 股 |
| 学习型专家混合路由 | 不采用 | 只有未评审的预印本 |

## 12. 大模型类与学习类策略的专门规则

1. 大模型的个股判断没有历史回测，只有前向记录。
2. 每次判断登记模型标识、训练截止日、提示词版本、输入快照。
3. 学习类模型固定三段时间：训练、验证、封存；封存段在名单写死后只打开一次；最终以逐日前向为准（经验卡）。
4. 学习类模型的产物以打分表进入平台，与规则类策略在同一仿真、同一门槛下比较，不享受任何例外。
5. 需要 PC 上的重型环境才能产出的分数，在进入“试用”之前必须导出成服务器能独立执行的形式。

### A.2 冻结主书 `book.main`

- 每个决策日取分数前 40 名，按分数从高到低买入尚未持有的股票，每天最多 4 只；20 个仓位，每仓 5 万元。
- 次日开盘买入；`hold_sessions = 6`，`exit_at = close`（旧记录里写作“持 5 日”）；不设止损止盈。
- 闸门：同一规则但不加闸门的那本账，若上一交易日收盘的净值低于它自己此前 20 个交易日净值的均值，当日新买入只保留 1 只（4 只的 0.25 倍取整）；已经持有的不减。
- 成本：旧记录口径为往返约 0.20%；新系统并排报告账户方案成本下的结果。

### A.3 持 10 日影子 `book.h10`

同一分数；每天最多 2 只，闸门触发时 1 只；20 个仓位；`hold_sessions = 11`，`exit_at = close`（旧记录里写作“持 10 日”）。判定：第 120 个交易日复查，扣成本后的超额大于 0。

### A.4 低换手篮子 `basket.x20`

每 10 个交易日调仓一次：股票池内剔除分数最低的 20%，等权持有其余；对照是股票池全体等权。判定：第 120 个交易日，扣成本后的篮子收益减等权收益大于 0。

### A.5 急跌冲击型超跌 `sel.os20_gap`

1. 20 日收益 = 当日收盘 ÷ 20 个交易日前的收盘 − 1（按该股自己的 K 线计数）。
2. 行业调整：减去当日同行业的池内均值；同行业不足 5 只时减去池内均值。
3. 超跌：调整后收益在当日池内排在后 10%。
4. 冲击：最近 20 根 K 线里，有一天开盘价比前收盘低 5% 以上，或收盘跌停。
5. 同时满足 3 与 4 的入选。次日开盘买，`hold_sessions = 10`，`exit_at = close`。
6. 判定用风格匹配超额与块自助法（块长 10）；第 60 个未标记决策日写中期报告，第 120 个判定。已知它依赖市场状态：历史上的效应几乎全部来自下跌市。

### A.6 尾盘选股 `sel.tail`

14:30 之后涨幅在 3%–5%；量比不低于 1；换手率 5%–10%；流通市值不超过 200 亿元；近 20 个交易日有过涨停。14:50 的价格买入，次日 10:00 前卖出；每天最多 5 只。判定：攒满 40 个交易日，扣账户方案成本后的平均收益与胜率，对照同时段随机入场。

### A.7 指数首尾半小时 `obs.index_first_last`

只是观察量，不产生交易：上证指数从前收盘到 10:00 的收益，与 14:30 到收盘的收益。判定：第 60 个交易日，回归斜率大于 0 且 t 不低于 2，并且主板等权序列同号。

### A.8 净值均线降仓 `ovl.equity_curve_gate`

如 A.2 的闸门：看的是“不加闸门的同一本账”的净值，不是指数。参数：均线 20 个交易日，触发时新买入保留 0.25 倍。台账的稳健性实验里，均线 10、15、20、30 日与保留 0.5、0.25、0 的 12 种组合回撤全部改善，收益在 15–20 日形成高原。

### A.9 议息反应日不新开仓 `ovl.fomc_reaction_day`

美联储议息声明公布后的第一个 A 股交易日，开盘不新开仓；其余不变。判定：累计 8 次议息后，比较冻结主书在反应日开盘成交的买入与其他买入。

### A.10 否决器

| 标识 | 规则 | 作用 |
|---|---|---|
| `veto.overbought_5d` | 5 日收益经 A.5 第 2 步的行业调整后，排在当日池内前 10% | 当日不买 |
| `veto.negative_announcement` | 最近 5 个交易日内有已确认的利空类公告：立案或处罚、减持计划、业绩预亏、问询函、被实施风险警示或退市风险 | 不买；持有时告警 |
| `veto.retail_seat_cluster` | 当日龙虎榜买方出现 3 家及以上被归为“线上个人账户归集地”的营业部 | 之后 10 个交易日不买；持有时告警 |

### A.11 防守基线：低风险复合 `sel.lowrisk_composite`

- 三个因子，都取“越大越好”的方向：5 日平均换手的相反数（成交额 ÷ 时点流通市值）；近 20 日最大单日涨幅的相反数；近 60 日日涨幅标准差的相反数。
- 股票池同 A.1。综合分 = 三个因子各自的当日截面百分位的平均；任一因子缺失的股票不入选。
- 每个决策日取综合分前 40 名作为候选（候选数是默认值，可调），按序补进尚未持有的；最多 20 只，每天最多新开 1 只；`hold_sessions = 21`，`exit_at = close`（旧记录里写作“持有 20 日”）。
- 它是防守基线：任何新候选都必须在同一时段、同一成本下打败它（07 卷第 6.1 节）。
