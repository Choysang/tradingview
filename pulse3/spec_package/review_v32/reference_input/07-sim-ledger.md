# 07 · 统一仿真、记账与晋升门槛

> 本卷回答：全平台唯一的成交规则是什么、唯一的账怎么记、业绩怎么算、一个策略要过哪些关才能影响推荐。
> 任何选股策略、个股操作策略、大模型判断、强化学习模型，都只能在这一套环境里被评价。

## 1. 为什么必须只有一套

审计（01 卷 A3）在现有代码里找到至少 15 套各自独立的成交与计分逻辑。同一个策略换一个入口，下面四项里至少有一项不同：

| 分歧 | 现状举例 |
|---|---|
| “持有 5 天”的含义 | 次日开盘买到第 6 日收盘卖；次日开盘到第 6 日开盘；次日开盘到第 5 日收盘。共四种 |
| 费用 | 生产路径一律约 0.20% 往返；用户拍板的约 0.252% 只出现在测试里；实验脚本里还有 0.10%–0.45% 的各种常数 |
| 涨跌停与停牌 | 到期日收盘封死跌停仍按收盘价卖出；卖出日停牌的交易有的记亏损、有的整笔丢弃、有的记 0 |
| 显著性 | 产品用逐笔独立同分布的 t 值判“有效”；研究侧用块自助法；两者结论可以相反 |

后果是研究里选出来的东西和产品里推荐的东西不是同一个东西，回测里赚钱和实盘里赚钱也不是同一件事。

## 2. 对象与流向

```text
策略 ──▶ ActionIntent（意图：对哪只、做什么、最高愿付价或最低愿卖价、何时失效、依据）
            │  组合层：预算、去重、否决、风险叠加、整手
            ▼
        OrderPlan（订单计划：数量、价格策略、交易时段、幂等键）
            │  SimExchange（回测、回放、纸面）或人工执行后回填（实盘）
            ▼
        ExecutionReport（状态迁移与成交）──▶ Ledger（复式分录）──▶ PortfolioState
            │
            └─▶ OpportunityRecord（每个触发过的意图都记录，没成交的写明原因）
```

- **意图不是订单。** 策略不知道账户有多少钱，也不决定买多少股；数量由组合层按统一规则给出。这样多个策略共用一个账户时不会互相透支。
- **机会账本。** 涨停买不到的信号不能从统计里消失。报告必须并排给出候选数、触发数、下单数、成交数，以及“买不到的那些后来怎样”。现状涨停开盘的信号被直接剔除，统计里看不到（已在设计 1.0 评审中确认为缺口）。
- **订单状态机**：`CREATED → SUBMITTED → ACKNOWLEDGED → PARTIALLY_FILLED → FILLED`，以及 `CANCEL_PENDING → CANCELED`、`REJECTED`、`EXPIRED`。撤单待确认期间订单仍可能成交。每次迁移是一条不可变事件。
- **四种运行模式共用同一段撮合与记账代码**：

| 模式 | 数据 | 用途 |
|---|---|---|
| 回测 | 历史数据，`AS_PUBLISHED` | 研究与初筛 |
| 回放 | 我们自己录制的盘中数据，`AS_OBSERVED` | 盘中策略与卖点的检验 |
| 纸面 | 每个交易日的真实数据，前向 | 影子检验；这是晋升的主要证据 |
| 实盘 | 用户在券商手动执行后回填成交 | 记录真实结果，度量实现缺口 |

平台不接券商接口、不自动下单。它输出订单计划，用户自己决定是否执行。

## 4. 成交规则

### 4.1 时间约定

- 信号只用**已完成**的 K 线或已到达的快照计算。
- 决策时刻之后的第一个可成交时点才允许成交。日线策略默认在下一个交易日的开盘集合竞价成交。
- **持有期只有一种写法**：`hold_sessions = N` 表示“把成交当天记为第 1 个交易日，在第 N 个交易日按 `exit_at` 指定的时点（开盘或收盘）卖出”。旧记录里的各种说法都换算成这一对参数。停牌日不计入。

  | 旧说法 | 实际含义 | 统一写法 |
  |---|---|---|
  | 旧组合引擎的“持 5 日”“持 10 日”“持 20 日” | 成交日之后再过 5、10、20 个交易日的收盘卖出 | `hold_sessions = 6 / 11 / 21`，`exit_at = close` |
  | 研究脚本里的 5 日标签 | 次日开盘到其后第 5 个交易日的开盘 | `hold_sessions = 6`，`exit_at = open` |
  | 预注册文件里的“次日开盘买、第 10 日收盘卖” | 字面含义 | `hold_sessions = 10`，`exit_at = close` |

  凡引用旧结果的地方都保留旧说法并注明对应的参数；新登记的策略只用统一写法。

### 4.2 日线模式

| 情形 | 规则 |
|---|---|
| 开盘买入 | 开盘价未在涨停价：按开盘价加滑点成交。开盘即涨停：进入排队模型（4.4） |
| 开盘卖出 | 开盘价未在跌停价：按开盘价减滑点成交。开盘即跌停：进入排队模型；未成交则顺延到下一个交易日 |
| 收盘买入或卖出 | 收盘价在涨停（买）或跌停（卖）时不成交并顺延。现状“开盘正常、收盘封死跌停仍按收盘价卖出”是缺陷（红队已复核） |
| 一字板 | 全天最高价等于最低价等于涨停价：买入成交量为 0。跌停一字板：卖出成交量为 0 |
| 盘中限价单 | 买单要求当日最低价低于限价至少一个最小单位才算成交；开盘已低于限价按开盘价成交 |
| 同一根 K 线里止损与止盈都触及 | 先止损。日线不提供盘中先后顺序，取对自己不利的假设 |
| 入场当天 | 不检查离场条件（T+1） |
| 停牌 | 订单被拒，原因记为停牌；持仓按最后收盘价估值；到期的卖出顺延到复牌后第一个可成交时点 |
| 退市 | 按规则表的清算规则在最后交易日强制了结 |
| 成交量上限 | 单笔成交不超过该 K 线成交量的 10%（另报 5% 与 25% 两档）；超出部分未成交 |
| 冲击成本 | 基线滑点之外，加一项随“订单量 / 日均成交量”增长的冲击；系数用我们自己的快照数据标定，标定前取 0 并在报告中声明“未计冲击” |

### 4.3 快照模式（回放与纸面的盘中部分）

- 订单在“到达时刻”进入队列，到达时刻 = 决策时刻 + 延迟。延迟的默认值是 3 秒（人工下单另设 30 秒一档），作为参数记录在每次运行里。
- 之后的每一帧快照按盘口与成交量推进队列。不凭空构造两帧之间的价格路径。
- 集合竞价、收盘竞价、盘后固定价格各有自己的成交条件；盘后固定价格的成交需要当日盘后确有成交量。

### 4.4 涨停价排队模型

没有逐笔数据时，封板买单能否成交是不确定的。统一做法是同时给出三种情景，并列报告，不取单一值：

| 情景 | 假设 |
|---|---|
| 乐观 | 到达时刻之后涨停价上的成交量全部可以分给我们 |
| 基准 | 排在我们前面的是到达时刻的买一封单；之后涨停价上的成交量先消耗前面的封单，剩余的才分给我们。跨越到达时刻的那一段成交量按时间比例切分 |
| 悲观 | 只有炸板时才成交 |

炸板一律按全额成交并打上“逆向选择”标记：封不住的板最容易买到，这正是打板回测虚高的来源（经验卡；台账追涨类全部为负）。

**没有盘中快照的历史区间**（2026-11-02 之前只有日线）无法推演队列，改用固定的成交比例：收盘仍封住的涨停板，乐观、基准、悲观三档分别按 1、0.3、0 成交；一字板三档都是 0；炸板三档都是 1。这组数值沿用本项目的经验卡。

三种情景差距大的策略，结论标记为“收益依赖未知的成交路径”，不得晋升。

## 5. 账本

### 5.1 复式记账

每一笔成交、费用、分红、送转都写成借贷相等的分录。科目：现金、冻结资金、持仓（按证券与批次）、应收（分红、卖出款）、佣金、印花税、过户费、已实现损益、分红收入、权益。

每个交易日结束时自动执行恒等式检查：期初 + 当日流水 = 期末；全部分录借贷相等；现金不为负；任一证券的可卖数量加当日买入数量不超过总数量。任一项不成立，这次运行整体作废并报警。

金额全部用定点小数。现状除一个账本模块外都用浮点数（审计 A3）。

### 5.2 批次与成本

- 持仓按买入批次记录。T+1 的“可卖数量”由批次的买入日期直接得出。
- 已实现损益按先进先出计算；界面同时显示移动加权平均成本，方便与券商软件对照。
- 买入先冻结资金，卖出先预占可卖数量；订单终结时释放未用部分。这条规则沿用已验证的 T+1 库存账本设计。

### 5.3 公司行为

- 成交与估值永远用原始价。
- 除权除息日：送转股按比例增加批次股数并摊薄成本；现金分红在派息日入账，红利税按规则表计算（税率规则待核）。
- 配股作为可选权利单独记录，默认不参与。

现有全部引擎都用复权价成交，也没有分红入账（审计 A3）。

### 5.4 账户

| 账户类型 | 说明 |
|---|---|
| 策略纸面账户 | 每个进入影子阶段的策略版本一个，标准初始资金，独立记账 |
| 融合纸面账户 | 推荐榜对应的组合 |
| 用户账户 | 用户回填的真实成交；用于度量实现缺口 |
| 旧制前向账户 | 从旧系统导入的冻结主书与影子账本，只读 |

推荐、持仓告警、推送都指向同一个账户实体。现状推送的是战法集成的推荐，新闻告警盯的却是另一套组合的持仓（审计 A4，红队已复核）。

## 6. 业绩度量标准

| 项 | 定义 |
|---|---|
| 日收益 | 时间加权：当日期末权益 ÷（期初权益 + 当日外部现金流）− 1 |
| 累计收益 | 日收益连乘 |
| 年化 | 几何年化，每年按 244 个交易日（10 卷 D06）；不足一年不年化 |
| 波动率 | 日收益标准差 × √244 |
| 夏普 | 日超额收益均值 ÷ 标准差 × √244；无风险利率是配置项，默认 0 并在报告中写明 |
| 回撤 | 相对历史最高权益的跌幅，取负值 |
| 胜率、盈亏比、期望 | 按已平仓交易计；未平仓的单独列出 |
| 换手 | 单边成交额 ÷ 平均权益 |
| 容量 | 在成交量上限 10% 的约束下，策略收益衰减到一半时的资金规模 |
| 实现缺口 | 决策参考价与实际成交价之差，按成交额加权 |
| 单位 | 契约与界面上的比率一律是百分点（字段以 `_pct` 结尾）；内核函数内部用小数，只在边界换算一次 |

所有报告同时给出费前与费后，以费后为准。

### 6.1 基准（全平台只有这一张表）

| 基准 | 定义 | 作用 |
|---|---|---|
| 市场 | 上证指数（用户指定的口径）与主板等权 | 只用于报告，不作为晋升条件 |
| 现金 | 收益为 0 | **必须打败**（扣成本后） |
| 风格匹配 | 同一天、同一市值五分位、同一波动五分位的股票的平均收益；格子里不足 5 只时退到同市值格子 | **必须打败**；“超额”一词在本规格里默认指相对它的超额 |
| 同日同池随机 | 每天从同一个可交易池里随机抽同样数量的股票，重复 1,000 次，取分位数 | **必须打败**（高于第 95 分位） |
| 防守基线 | 低风险复合（06 卷附录 A.11），同一时段、同一成本 | **必须打败** |

依据：台账 E062 显示，改用风格匹配基准后 46 套产品战法与 10 个实验室信号在两个时段无一存活，此前的“超额”主要是低波动风格的溢价；长周期评测显示复杂方法的优势在宽截面上大幅缩水（09 卷）；本项目的学习类方法在风格切换后全部输给防守组合（经验卡）。

晋升门槛（第 8 节）与联赛（06 卷第 6 节）用的都是这四个“必须打败”的基准。

### 6.2 短线账本的三段拆分

持有不超过 5 个交易日的策略，每笔收益固定拆成三段报告：入场当日日内、隔夜跳空、之后日内。依据：本项目经验卡显示主板高换手股票的亏损主要在隔夜；文献显示 A 股隔夜收益显著为负且彩票型异象主要来自隔夜（09 卷）。

## 7. 统计防线

| 问题 | 统一做法 | 依据 |
|---|---|---|
| 持有窗口重叠导致 p 值偏小 | 移动块自助法，块长不小于持有天数；或 Newey-West，滞后不小于持有天数减 1 | 台账 E082：换成块自助后，一批“显著”结果从 32 个降到 21 个、7 个降到 0 个 |
| 测得越多假发现越多 | 每个策略家族登记累计试验数；用收缩后的夏普（Deflated Sharpe）与错误发现率控制；家族内比较用模型置信集 | N 个无效策略里最好那个的 t 值期望约为 √(2 ln N)，N = 1,000 时约 3.7（本项目 2026-11-08 的闭环评审）；469 个中国异象里约 83%–87% 不显著，比例随口径不同（09 卷，片段级） |
| 样本内外切分被污染 | 时段边界是写死的日期，不随数据增长滑动 | 现状切分点是“数据长度的 70%”，每天后移（红队已复核） |
| 选择过程本身过拟合 | 对“从 N 个里选最好的”这个过程估计过拟合概率（PBO）；封存一段只开一次的数据 | 09 卷 |
| 随机数与排序不稳定 | 所有分组结果先按日期排序；随机种子记录在运行账本 | 台账 E082 发现旧的 t 值算在未排序的序列上 |
| 引擎与统计本身是否正确 | 植入已知答案的合成数据：无信号的序列应得到不显著的结果，植入已知收益的序列应被检出 | — |

这是用户 2026-11-02 拍板的口径，原样继承。接入更长历史后，PRE 的起点前移，其余不变。

## 8. 晋升门槛

策略的生命周期状态在 06 卷定义。这里给出每一级的通过条件。数值是默认值，可在 10 卷 D07 调整；调整本身要登记。

| 晋升 | 条件 |
|---|---|
| 提出 → 已登记 | 规格完整；预注册写明假设、判定标准、时段、最小样本，且登记时间早于第一次看结果；无前视测试通过；标准用例通过 |
| 已登记 → 候选 | 在 PRE 与 DEV 两段上：扣账户方案成本后，风格匹配超额都为正；PRE 段块自助单侧 p < 0.05；成本 ×2 后仍为正；基准情景与悲观情景方向一致；触发不少于 200 次且覆盖不少于 60 个交易日；收缩后的夏普按家族试验数计算后仍显著；打败防守基线 |
| 候选 → 影子 | 版本冻结；开立纸面账户 |
| 影子 → 试用 | 前向不少于 60 个交易日（`hold_sessions` 超过 6 的不少于 120 个）；前向风格匹配超额为正并打败其余三个必须打败的基准；实现缺口在回测假设的区间内；并且在联赛里连续两轮具备晋升资格（06 卷第 6.2 节） |
| 试用 → 正式 | 前向累计不少于 250 个交易日；连续两个季度没有触发衰减告警；联赛里连续两轮具备晋升资格；在融合里的权重上限由 10% 放开 |
| 任何状态 → 休眠 | 滚动前向超额的置信区间上界低于 0，或它依赖的市场状态不再成立；休眠不删除，状态恢复的条件写在规格里 |
| 任何状态 → 已证伪 | 预注册的判定标准明确不成立。规格与全部结果保留，作为之后同类想法的拒绝先验 |

四点说明：

1. **各状态能做什么**只看 06 卷第 5.1 节的权限表。要点是“只减不增”：否决、风险标记、告警、把仓位调低，在“候选”时即可生效；让股票排得更靠前或把仓位调高，必须到“试用”。
2. **前向证据优先于回测证据。** 大模型类策略没有“已登记 → 候选”这一步的历史回测：历史上的大模型判断含泄漏（09 卷多项证据），它们从登记直接进入影子，只靠前向记录晋升。
3. **证据稀少是事实，不是缺陷。** 样本外从 2026-11-02 才开始，所以相当长的时间里“正式”一栏接近空白。推荐榜在这段时间照常产出，但每条推荐都标明它背后策略的证据等级（06 卷第 7 节）。
4. **负面证据同样有用。** 被证伪的追涨类规则、被验证为负的席位跟随，转成否决器与风险标记继续服役。

## 9. 标准测试套件

### 9.1 成交与记账的标准用例（每条都是一个可执行测试）

1. 开盘即涨停，买单在三种情景下的成交量分别正确。
2. 全天一字涨停，买入成交量为 0，机会账本记录“一字板”。
3. 炸板，买单全额成交并带逆向选择标记。
4. 到期日开盘正常、收盘封死跌停，卖出顺延。
5. 连续两日一字跌停后打开，卖出在第三日成交，持有天数与收益正确。
6. 持仓期间停牌两个月后复牌下跌，收益记为真实跌幅，不丢弃、不记 0。
7. 买入当日触及止损价，当日不卖，次日处理。
8. 同一根 K 线同时触及止损与止盈，按止损处理。
9. 现金只够 2.7 手，买入 2 手。
10. 卖出 300 股中的 250 股后余 50 股，余股只能一次性卖出。
11. 佣金不足 5 元按 5 元收取；印花税只在卖出时收取；过户费双向收取。
12. 2026-07-03 与 2026-07-06 的同一只主板 ST 股，涨停价分别按 5% 与 10% 计算。
13. 除权除息日：送转后批次股数与成本正确；现金分红在派息日入账；复权收益与账本收益一致。
14. 高分红股票在无除权的季度里，原始价与复权价之比恒定。
15. 正 T：买入用的是当日开盘建仓后剩余的现金，不是当天收盘才到账的卖出款。
16. 倒 T：卖出底仓后当日买回；买不回的部分从持仓里减掉；买回的股票次日才可卖。
17. 两个策略同时对同一只股票发出买入意图，组合层只下一单并按规则分配归属。
18. 订单在撤单待确认期间成交，账本结果正确。
19. 幂等：同一幂等键重复提交，只记一笔。
20. 盘后固定价格：有盘后成交量时按收盘价成交，没有时不成交。
21. 成交量上限：订单超过当日成交量的 10% 时部分成交，其余未成交并记录。
22. 退市整理期最后一日强制了结。
23. 账本恒等式：任意随机生成的订单流，每日检查全部成立。
24. 时点测试：数据截断到任意一天后重跑，此前的全部成交与净值不变。
25. 无信号合成数据：一组随机策略的显著比例不超过名义水平。

### 9.2 对照套件

- 四个基准（第 6.1 节）。
- 成本三档、成交情景三档、成交量上限三档。
- 与一个外部开源引擎用同一组信号交叉对账成交与净值（可选；注意对方的许可条款）。
- 回测、纸面、实盘三者的偏差监控：同一策略同一时期，纸面与回测的逐日收益差超过阈值即告警。

### 9.3 迁移期的并行对账

新引擎上线前，用旧系统冻结主书的历史信号在新引擎里重放，逐笔比对。差异必须能逐条归因到本卷列出的规则变化（例如收盘跌停顺延、最低佣金、原始价成交）。不能归因的差异是缺陷。
