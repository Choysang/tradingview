# 05 信号卷、06 策略卷独立深评

审查对象：`upload/05-signals.md`、`upload/06-strategy.md`。完整逐段阅读后，将 404 个 `requires_decision=true` 实质单元分配给 140 条决议，覆盖率 404/404，无遗漏、无重复。机器可读证据、理由、实现动作、验收与遗留不确定性见同目录 `signals_strategy.json`。标题不计入实质单元。

审查基准是现有 `deliverables/Pulse_Rewrite_Package` 的正式合同，而非归档旧版本。核读旧仓库固定 HEAD `6f5c57f8df73c58f0340dab6977b95c05d21740c` 的相关代码和实验台账。本次没有重跑旧实验，没有访问生产或真实账户；台账数字在本文中只表示“旧记录自报”，不表示本轮复现。

## 1. 总体判断

两卷值得吸收的内容很多：消息原文与实体链接、来源独立性、更正关系、社区观点到期评价、席位实体、五轴状态、板块升温冻结、策略形式化、父版本谱系、固定入场比较退出和失败记忆。这些具体功能可以加强现有设计。

但它们尚不能原样作为完整可执行规格。主要缺口不在于策略数量，而在于四处权力转换没有闭合：事实如何取得交易影响权、未验证策略如何提供首日榜单、不同信号如何进入同一个分数、研究比较如何取得生产准入。上传卷在这些地方多次用文字性的“已确认”“只减”“统计显著”“同质”“已证伪”跨越必要定义。

本审查保留用户要做的选股、板块榜、个股计划、正反 T、网格、多范式策略池和未来并行 Agent 开发。对未证明的方法保留清晰研究入口；对已有局部失败保留精确范围。既不将论文或模型的预测当成已经证明的收益，也不把一次失败写成永久的方法禁令。

## 2. 首先必须修的六个主干问题

### 2.1 “只减不增不会亏损”不能作为低门槛交易权限

05 卷第 3.2 节允许未确认消息触发 VETO，第 3.5 节又要求确认。06 卷第 5.1 节进一步把候选与影子策略的 VETO、RISK、POSITION 只减当成低门槛能力。若 RISK 只是标签，问题较小；若它扣排名分、VETO 删除第一名、POSITION 平仓，就已改变账户决策。

反例非常直接：卖出会实现损失并产生成本；避开一只上涨股而自动替补一只下跌股会降低净值；删除对冲持仓也可能提高组合风险。行动方向为“减少”不意味着效用单调改善。把这种动作称作“风控”不会改变其需要评价的事实。

建议将权限分为四类：

| 能力 | 决定它的依据 | 是否需要策略效果验证 |
|---|---|---|
| 原文与事实提醒 | 支持该声明的来源、原文版本、核验状态 | 不需要先证明股票收益效果 |
| 有效交易制度 | 当前证券、市场、账户、日期适用的 RuleSet | 不与预测策略竞争 |
| 用户明确偏好 | UniversePolicy、账户操作配置 | 显式执行并说明影响 |
| 预测性否决、减仓、退出、排序惩罚 | 对应角色、目标、母集、成本下的 EvidenceScope 与 CapabilityGrant | 必须能定位独立评价及使用授权 |

候选策略可以开始影子干预，影子账户与不干预账户并排比较；“权重为 0”意味着它不能通过另一条 VETO 路径悄悄改变真实结果。相关决议：SS003、SS015、SS025、SS080、SS081、SS138。

### 2.2 冷启动主干仍有断供和权重放大漏洞

上传卷规定旧制融合分承担临时主干，一旦同榜出现一个“试用”策略就取消例外；同时试用策略单个最多 10%。这留下两种错误实现：剩余 90% 没有定义，或将唯一候选的 10% 再归一化成 100%。

应补 `RankingContinuityPolicy`，它至少定义：最终归一后的策略预算上限、残余基线份额、最低输入覆盖、无合格候选的表现方式、替换条件、回退条件和发布版本。首日可以正常提供标明状态的研究候选榜与条件计划，不需要编造“已验证”冠军；研究功能完整与证据等级诚实可以同时成立。

三个记录轨道必须分开：

1. 原冻结旧主书：保存原股票池、原规则、原费用、原首次分数，用于延续观察。
2. 兼容移植书：验证新实现能否在同输入同规则下复现旧行为。
3. 当前产品书：使用用户明确的沪深主板、股价不超过 100 元、**流通市值不超过 100 亿元**，以及新合同和当前费用；它拥有自己的定义和前向起点。

给旧书添加三个否决器和新仓位层，就产生了新组合，不能继续声称原冻结定义不变。A.6 的 200 亿元上限只能作为独立历史研究池保留，不能覆盖用户默认推荐池。相关决议：SS073、SS082、SS103、SS106、SS123、SS134。

### 2.3 “全部投票者为分母、未选中记 0”不够明确

至少五种情况应分开：实际分数、明确负面判断、不适用、策略弃权、缺失数据。0 分既可以是最差百分位，也可以是中心化后的中性；若系统不区分，缺新闻源的一只股票会被当作所有新闻策略一致看空。

按固定全部权重作分母确实可以抑制少数投票虚高，但会引入缺失惩罚。按有效权重归一可以保持尺度，却会在缺席时放大剩余策略。两种算法都不是天然正确，必须在明确目标和缺失政策下选用。可用方案是：同目标校准、明确中心值与负向、最低覆盖、残余基线、最终权重上限、覆盖不足的显式状态。

IC、净超额、上涨概率、风险提示和 MACD 数值不能直接平均。它们需要先被转换成同一个预测目标上的量，或保持各自职责。allocation 改资金预算，entry 改进入条件，execution 改委托方式；它们不必变成同一张“综合评分”。相关决议：SS002、SS092–SS095。

### 2.4 程序映射不等于模型退出决策

模型输出“利空”，代码映射成 −1，最后扣分，仍然是模型影响排序。枚举输出有助于校验，但不能证明判断可靠。反过来，若一个预测模型经适当校准、冻结和评价，禁止它输出概率或排序分也没有必要。

建议保留两种不同任务：抽取任务输出事实声明及证据片段；预测任务输出有目标、单位、期限、置信与校准依据的数值。两者都登记模型版本、提示版本、输入快照、检索快照、运行时间、费用和重试行为。能力权力由用途证据决定，不由输出是不是数字决定。相关决议：SS023、SS024、SS076、SS121、SS122。

### 2.5 高相关不是等价；统计无法区分不是已经证明相同

两策略相关 0.9，可以在大多数平稳日很像而在危机日显著不同。样本少时未检出配对差，也不能证明没有差。若进一步按绝对相关聚簇，方向相反的信号可能被合并，丢掉分散或对冲信息。

应先合并完全相同的代码、参数、模型和数据身份。相似家族用于预算和重复检验控制，同时保留带符号相关、条件表现、尾部暴露、成本与容量。是否去掉一项由组合内边际贡献决定，而非仅靠 0.8 阈值。组合本身必须成为新版本，重新跑同一本账户。相关决议：SS085、SS089、SS090。

### 2.6 旧实验的失败范围多次被扩大

旧台账对许多条目已经使用 mixed、inconclusive 或明确 reactivate_when，上传卷反而写成“所有状态路由失败”“技术买点全部不成立”“倒 T 有害”“网格不是收益来源”。这些是超出证据的推广。

| 已核读旧条目 | 它真正研究的范围 | 不能推出的结论 |
|---|---|---|
| E006、E020、E042 | 特定 LightGBM 战法选择、固定月份状态聚类、类比日组合 | 任何状态条件选股或学习路由都无效 |
| E011、E014 | 指定窗口的因子融合；台账为 mixed | 所有动态权重都应禁止 |
| E023 | 2/5/20/60 持期与指定正反 T 参数；部分正 T 结果小幅改善 | 所有做 T 都有害或不可能增加收益 |
| E033、E061 | 传统规则电池；特定缠论实现与其前视修复 | 所有技术条件、严格新实现永久证伪 |
| E070 | 特定超跌/超涨样本、标题规则与条件后续收益 | 所有利空公告都适合统一五日否决 |
| E072 | 部分美股指数日收益；未用 A50、离岸人民币、金油 | 全部国际信息都已被集合竞价吸收 |
| E074 | ETF 放量描述；强反弹子集为结果后切分，约四段行情 | ETF 放量即可识别国家队或应停止卖出 |
| E075 | 规则告警部署与无模型密钥回放，前向待积累 | 利空后卖出已经证明有效 |
| E083 | 历史指数 FOMC 反应日的开盘至收盘收益 | 当前股票主书避开该日开仓已经验证 |

这些旧结果值得继承。继承的方法是绑定 `spec_hash + data_manifest + context + cost_profile + outcome + limitations`，而不是把方法名字永久拉黑。相关决议：SS005、SS007、SS011、SS026、SS043、SS075、SS100、SS101、SS114、SS117。

## 3. 消息、社区与席位应怎样连接

### 3.1 多源核验到“声明”层

T0/T1/T2/T3 可以保留为来源目录默认层级，但不应成为二票真值机。T1 不必等 T2 转载才可报告一份已确认公告；两家 T2 可以共同引用同一个错误上游；一份 T0 文档也未必支持标题概括出的全部数字。

核验对象应是原文中的声明：谁，在何时，做了什么，涉及什么数量、对象和状态。保存支持、反驳、转引、修订、撤回及根来源。更正只追加新版本，既改变当前投影，也保留过去告警与判断用于回放。

无法链接具体证券的新闻不能直接丢弃。它可以关联市场、行业、产品、地缘或 unresolved entity；谐音、曾用名和民间题材关系可以作为带来源的候选关系保留，但不能混成主营业务事实。

计划事件轮询只是增密机制。还需低频健康检查、游标补拉、迟到发布重试和非例行事件入口，才能发现错过日历窗口的消息。实际接收与计算完成时刻不改写成新闻自报发布时间。相关决议：SS012–SS022、SS055、SS056、SS062、SS063。

### 3.2 社区与散户画像要区分测量对象

帖子量、阅读量、热榜排名、粉丝数与小单成交是不同变量。不同平台、不同时间段需各自基线；缺采样不能填零。盘前、盘中、午间、盘后四阶段都应有独立快照。

评论预测需保存原始版本和明确目标窗口。没有概率声明时不能硬套概率评分；事后编辑或删除不能改变原预测。未来结果未成熟就保持 pending。后来找到的历史预测可以是独立回顾样本，不能混入真实前向捕获队列。

小账户交易方向的研究不等于所有股吧用户的观点应反向操作；热度高也不自动获得 VETO 权。社区与平台判断并排展示值得继承，经过校准的社区模型仍可作为正常候选研究。相关决议：SS031–SS034、SS064。

### 3.3 龙虎榜不能恢复真实账户持仓

公开龙虎榜的营业部、匿名机构标签与完整交易账户不是同一层数据。机构专用不能按相同文字跨日拼成一个持续账户。更名迁址可以用稳定席位实体与别名有效期解决，昵称则保留未证实来源。

后续收益、再次上榜间隔、偏好市值、同榜关系可以从披露事件统计；真实持有天数、完整仓位和单一账户身份通常不能由这些披露反演。原文“持有天数分布”应替换为可观察指标或标不可得。

席位信号必须保留全部当时出现的候选，再分别报告可成交订单、未成交与账户收益。事后剔除次日涨停买不到的事件会改变样本；30 次同一主题共振也不能当 30 次独立经验。相关决议：SS035–SS039。

## 4. 技术图表、市场状态与板块榜的实现闭合

### 4.1 图表值需要共同数学合同

至少要明确：raw 与 PIT 调整价格、收益基准、成交量单位、EMA 初始值、MACD DIF/DEA/柱线及国内常见 2×柱线约定、KDJ 平滑、ATR 前收处理、标准差 ddof、截面并列、预热、缺值和跨会话窗口。名称相同不代表公式相同。

周/月/季/年线应由同一交易日历和聚合服务构建。已完成周线在该周最后交易日收盘后实际处理完成时可用，无需硬延迟到下一周；未闭合周线单列 `is_final=false`。分型图上锚在过去低点，不表示过去低点当天已知道分型；`anchor_at` 与 `available_at` 必须分开。

前端可以做格式化和注明 preview 的交互预览，但生产发布值来自同一权威算法/版本。截断测试之外还需要修订、除权、缺失和确认时间的固定反例。相关决议：SS044–SS047。

### 4.2 板块角色不能替代板块总榜

用户希望进入任何板块都看到该板块最值得关注的股票。角色分栏有帮助，但只允许角色内排序会留下“中军第一与龙头第二该怎么比较”的空白。产品应同时提供同目标的板块研究榜/可行动榜，以及龙头、中军、跟风、补涨分栏。

规则角色是可计算解释，不是预测保证。非涨停但涨幅前 20% 的股票没有首封时刻，不能随后强制判断它“封板晚于龙头”。板块成员重叠时，top3 题材涨停占比必须取唯一并集或明确分摊，否则可超过 100%。拥挤惩罚幅度、z 分母和零方差处理也必须写进公式。

升温触发时冻结原候选、板块成员、规则和全部特征，后续一、三、五、十日评价保留失败与未成交。冷却期只抑制重复触发，不能禁止新事实更新。相关决议：SS049–SS061。

## 5. 联赛与操作策略的具体落地

联赛分组沿用现有六职责，进一步固定目标、期限、母集、数据等级与 EvaluationContext。family 用于试验预算和重复检验控制，不能把规则、树模型与 RL 选股隔离成互不比较的冠军组。

同组配对保留逐日差、依赖结构、成本与共同有效窗口。20 个交易日一轮是运营节奏，连续两轮资格是迟滞机制；它们本身不产生独立统计证据。MCS 可以保留“无法区分的相对最佳集”，即使所有候选都差也可能仍有成员，所以必须另看角色适配基准与经济效应。

现金适合作为组合机会成本；不适合作为因子 IC、概率校准或委托质量的统一基准。固定防守股篮子同理。执行策略应比较同订单的成交改善，退出策略应固定同批入场并声明再投资政策，组合策略最终由唯一账本给出同初始资金的净财富。

正反 T 和网格照常提供，但每腿都使用真实可卖库存、现金预留、整手、费用和实际可成交路径。显示持仓成本下降不能代替净财富增加。8% 止损与 2×ATR 比较必须先将 ATR 除以参考价格；“保本”价还要考虑真实费用。盘后会话按证券/日期的有效交易制度授权。

相关决议：SS069、SS084–SS102、SS112–SS120。

## 7. 交付到正式包时建议新增的有限对象

这些是补充合同，不应另建一套并行架构：

## 8. 关键验收反例

1. 唯一试用策略预算10%，不会归一成100%；其余预算明确来源或显示空缺。
2. 未确认传闻只形成带来源提醒，不通过VETO暗改生产排序。
3. 旧书加入新否决器生成新组合，原冻结书继续可回放。
4. 缺新闻源不变成负面0分；明确看空与弃权有不同payload。
5. 完成周线周五晚可用，未完成周线不冒充最终；图上历史分型只能从确认日参与决策。
6. 相同机构专用文字不会拼成持仓账户；真实持有天数保持不可得。
7. top40高度重合但实际买入不同不能通过交易级Parity。
8. 200亿历史尾盘池不会覆盖当前100亿默认推荐池。
9. 仅改变隔夜收益不会改变开盘后首半小时特征。
10. 价格下跌触发止损但T+1/无对手不能卖时，账本保留库存与真实亏损。
11. 高相关但尾部表现不同的策略不会被自动删除；反向信号不因绝对相关被合票。
12. 8次宏观事件里400条股票记录仍按8次事件的依赖结构评价。
