## 四、41 条代码发现的综合评判

多数具体方向成立，尤其是：

- 昨日涨停池从今日赢家倒推；实时连阳前态硬编码 0；自由流通市值乘固定 0.62；处理时间冒充交易日期；未知涨停价返回 0。
- 调度三步各自执行，前一步失败仍报告并推送；完成水位只看报告生成钟；API 与 CLI 可绕开同一写入所有权。
- 日线缓存以自然日判新鲜；跨源前复权口径可能混用；证券主表只保最新；小额分红无法由 0.5% 阈值可靠发现；缺失快照证券不进入补抓计划。
- 固定窗口收益函数把停牌样本返回 None；收盘跌停可能被记为卖出；席位标签没体现成本与可执行性；回放权重和线上权重并非同一 policy。
- GET 可能覆盖已发布推荐；旧 schema 失败静默丢档；页面缺业务版本事件；报价整对象覆盖详情历史字段。
- 新闻源临时失败达到次数后当天无法恢复；告警只在文件层，未通产品；缺全时段游标补洞；跨源未区分转载与独立证据；固定 lag 冒充真实可知时刻。

以下三处不能按原结论采纳：

**第一，现金在下跌期跑赢基准不是记账错误。** 现金收益 0，市场跌 10%，相对超额为正是正确的。缺陷是把择时/防守贡献当作选股能力，或者用不匹配角色的门槛晋升。修法是分解 selection、allocation 与 cash exposure，并使用角色基准。

**第二，原文“净收益 +0.22%，换账户费率后转负”缺算术依据。** 默认成本约 20 bp，材料账户约 25.2 bp，增量只有 5.2 bp。若 +0.22% 已经是默认费后净收益，更换同规模费率后仍约 **+0.168%**。精确的示例乘法核算也为正。如果原作者实际指毛收益，需要改术语并给原始底账。费用没有全链统一仍然是缺陷，但这个负收益例不能作为证明。

**第三，50% 手工技术/情绪/趋势子分“未被整体回测”成立，“因为单指标无效所以组合必无效”不成立。** 条件交互可能产生不同效果，应按完整融合版本做消融和前向增量检验；不能凭单指标结论直接删除用户需要的技术分析功能。

健康检查也应精确表述：liveness 返回 ok 可以合理，错误是拿它代替数据 readiness。SSE 本身已有重连与静默 watchdog，缺的是数据集、报告、策略版本的业务变更事件，不应重写一个平行心跳体系。

## 五、52 条继承规则中需要替换的重点

### 1. 数据规则

比例复权可以保留，但因子方向和锚日是供应商契约，不能把 raw/factor 写成所有来源统一的事实；实际成交必须 raw 价。复权变化发布完整新版本，不能混锚，也不能把迟到的旧来源视为“最后写入所以最可信”。

日线完成不能永远固定 15:05。当前工作树已有 15:30 局部修复；新系统仍要按历史生效日期、交易会话和源数据水位区分 provisional 与 final。证券身份不以同名合并；北交所换码必须正式 ID 与有效区间。缺上市日保存年龄下界，不能凭面板首日已交易编造“老股”年龄。

历史市值优先当时股本。用当前市值按旧价缩放属于近似，严格 PIT 评测不能悄悄把它用于风格匹配。98%/95% 覆盖率、18:00 才查龙虎榜和低于 2 元过滤都属于可配置政策或采集经验，不是通用交易制度。

日期精度独立字段表达，不以 00:00 魔法值表示“只有日期”。交易日由日历定义，报价多数日期只用于识别源陈旧状态。

### 2. 新闻与模型调用

保留首见时间、修订 hash、supersedes、调用前账本和 deadline。把 `AS_OBSERVED`、`AS_PUBLISHED`、估计可知时刻分开：历史发布时间可用于某类研究，不等于本系统当时已看到。

“首轮全部不触发”需要改为启动状态、游标与新鲜度政策；初次成功响应也可能有刚发生的新事件，不能无条件丢掉。过期持仓不能生成确定卖出数量，但也不能静默当成零持仓，必须显示持仓状态未知。

E088 不能支持“仅标题规则已验证”。实际有无标题取前 120 字、部分严重事件取前 300 字等例外，44 条开发样本同作者定规则与标注，真实持仓 P0 样本为零。它支持继续做实体归属、分句否定、前向盲标测试；不支持自动将全文信息弃用。

### 3. 持仓与评测

T+1 约束新买批次，不禁止已有底仓做 T。卖出款可交易与可提取是不同概念；“倒 T 资金不给新仓”可以作为预算政策，不应冒充结算制度。每日滚动因子买入只是一个再平衡方案，不必强迫周调仓、长线或稀有事件策略采用同样日程。

周/月线在周期最后交易日完成并可知后即可用于决策；下一周期首日是某个策略延迟，不是数据物理上只能那时可得。截断不变只针对固定可知输入和不虚拟强平的前缀；历史修订新版本与前视错误要分开。

块长不小于持有期只是下限。E082 自己就记载短 DEV 只有 3–4 个块时显著性可能被反常放大。固定日期也不等于所有新模型都自 11 月 2 日起有前向身份。

## 六、07 卷经济内核必须修订的七处

### 1. 时间加权收益

材料公式 `期末/(期初+当日全部外部现金流)-1` 不适用于一般现金流时点。10000 → 11000，入金 9000 后资产 20000，再涨到 22000：精确 TWR 为 `1.1 × 1.1 - 1 = 21%`；材料算式为 `15.789%`。保留 v3.1 已有的分段链接法。没有流量时点估值时可明确报告 Modified Dietz 近似，不能称精确 TWR。

回撤也应基于流量调整净值；否则大额提现被误判策略回撤。

### 2. 退市与停牌

淘汰“最后交易日强制了结”。没有可成交市场不能创造现金。深交所 2026 风险警示指南也明确提示可能无法在终止上市前卖出。未卖出保留残余权益或非流动资产状态；减记是估值事件，清算到账是现金流事件。最后交易日、退市日、权益最终注销和清算日不能合并。

停牌仍保留逐日资金占用与估值陈旧状态。复牌或跌停打开只代表可能可成交，还须有有效委托、可卖量、时间与成交量。

### 3. 一字板、炸板与排队

一字板可以有市场成交。日线无法知道自身队列位置时，保守场景设成交 0 合理，但不能把市场成交量改为 0。

炸板不必全额成交：订单可能晚到、开板量太小、价格不符、已经撤单，或开板发生在到达之前。固定 1 / 0.3 / 0 只可保留为旧结果复刻 profile，不能作为新统一撮合器的权威概率。

乐观/基准/悲观是场景假设，不自动是真实成交上下界。到达跨帧的成交量按时间比例分割也是估计。参与率要按证券与时间区间聚合所有策略订单；不能每笔 10% 然后拆十笔突破容量。

### 4. 公司行动与可用资金

除息时确认应收分红，支付时将应收转现金；否则除息日假亏损、支付日假盈利。新增红股数量和上市可卖时间分开。配股默认不参与是一种账户选择，权利到期及价值变化仍要记账。

现金 total、reserved、available_to_trade、available_to_withdraw 区分。冻结现金不能加成额外资产。预占和释放应按订单状态幂等；当日委托到期后下一会话重发新单，不继承昨日队列。

### 5. FIFO 不应另立第二套权威盈亏

当前 v3.1 已定 `weighted_average_gross` 与交易费用单列。材料改成 FIFO 已实现、平均成本展示，会重新制造两套用户理解。批次继续用于可卖资格和税务追踪；若未来真支持其他会计政策，要独立 `accounting_policy_id`，同一账户始终一致。

### 6. 指标不止一个“统一名字”

换手必须给实际分子：买、卖、买卖和，以及若采用半周转则除以 2。实现缺口不只已成交价差，还包括决策延迟、费用和未成交机会成本。容量不能对所有策略定义为“收益跌一半的资金规模”，负收益、非单调或无交点时未定义；应给规模—成本—成交率—净收益曲线。

所有比率改 `_pct` 会破坏当前已统一单位体系。按字段单位字典转换一次即可，IC、概率、权重、费用 bp 不能仅凭显示习惯改成同一种数。

### 7. 检查失败不抹掉事实

复式平衡和现金/库存约束逐事件验证，日终再对账。研究 run 可以标 invalid，但保留轨迹。真实成交即使本地认为不合法，也须保存实际外部事实并进入 reconciliation，不能让“整体作废”抹掉真实账户。

## 八、晋升、联赛与冷启动

材料的“只减不增”权限需要删除。否决某股、降仓、提前离场都会改变收益、暴露、成本和机会，不是无经济影响动作。候选可以展示解释和进入影子；要改变正式排序/权重/数量，就必须证明组合增量。T+1、资金预算等硬规则直接执行，原因是制度或账户约束，不是因为被当成一条未经验证的盈利策略。

四基准可做报告参照，不能全部成为所有角色硬门：选股比同日同风格与同池随机；配置比同信号固定仓位；做 T/网格比同底仓静持；执行比同意图另一执行方案。角色不一致的比赛会淘汰本来达成目标的功能，也会把现金收益冒认成选股能力。

200 次、60/120/250 日、两轮和 10% 是设计参数，应该按事件频率、依赖、效应量和功效预注册。样本少为 inconclusive，不自动证伪；连续重复看 p 值需要序贯处理。

没有正式策略时，仍要产出用户需要的观察榜、板块候选与个股计划。冻结旧主干可作为 legacy，透明基线可作为 exploratory，但不得加已验证标签。首个试用策略占 10% 时，剩下 90% 必须有明确基线或现金/观察分配，不能立即停旧主干造成断供。**晋升改变状态，组合分配仍由完整、有守恒定义的 allocation policy 决定。**

## 九、25 个标准用例的处理

全部用例已在 JSON 单元中逐项给出决议。保留费用、整手、撤单竞态、幂等、库存、统计校准和旧新对账方向；修正以下答案：

- 炸板必全额 → 到达后可用量、订单资格和容量决定 partial / unfilled。
- 第三天开板必卖出 → 仅在有效委托且有可分配成交量时卖出。
- 退市末日强制了结 → 保留残余权益，减记与现金清算分事件。
- 300 先卖 250 留 50 → 先验证前单是否符合该市场规则；用合法零股来源构造样例。
- 分红只支付日入账 → 除息应收、支付转现金、税独立。
- 有盘后量即成交 → 市场有量是必要证据，不保证我的队列成交。
- 任意随机订单每日都应成功守恒 → 有效流保持不变量，非法流原子拒绝；拒单也可验证正确。
- 随机零效应每批显著比例必≤alpha → 用误报率置信带与功效校准；5%是概率水平，不是每次测试硬上限。
- 任意截断全部净值永远一致 → 固定可知版本且不虚拟期末平仓的共同前缀一致；合法重述另版本。

外部引擎对账值得做有限样例，但对齐经济假设之后再比。两个库同结果不排除同一错误假设，仍需要手算 golden 和复式不变量。
