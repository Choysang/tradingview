## 三、 数据库顶层设计：海量存储、统一命名规范与多源校验补齐

面对全市场 5,300+ 只 A 股的全周期 K 线（Tick/1m/5m/15m/30m/60m/日/周/月/年）、逐笔委托成交、每日数万条财经快讯与股吧热帖、龙虎榜历史席位明细，单一数据库必然产生 I/O 阻塞。系统采用 **2026 OLTP + OLAP + Stream 三层混合存储架构**：

1. **热态流与总线层（Redis 8 / DragonflyDB + NATS JetStream）**：承载盘中实时快照、多源轮询心跳锁、WebSocket 增量广播，保证策略层零阻塞读取（延迟小于 1 毫秒）。
2. **关系与业务状态层（PostgreSQL 17 + TimescaleDB）**：存储统一数据字典、策略分类标签树、瑞士轮比赛积分账本、个股工作台持久化配置（画线、底仓、做T计划、网格参数）、GIPS 标准复式记账流水。
3. **海量列式分析与回测层（DuckDB 2.0 + Polars 2.1 + Apache Parquet / Arrow IPC）**：按 `year/month/symbol_group` 分区的 ZSTD 压缩 Parquet 湖。Polars 2.1 与 DuckDB 2.0 通过 Apache Arrow C Data Interface 实现内存零拷贝互操作，10 年全市场分钟线回测扫描仅需数百毫秒，内存占用控制在 500 MB 以内。

### 3.1 全局统一字段命名规范（Canonical Naming Standard）

严禁在入库后出现 `vol`/`volume`、`code`/`symbol`、`amt`/`turnover` 混用的情况。所有表强制执行以下命名宪法：

* **标的主键**：统一为 `symbol_id`（格式：`{EXCHANGE}.{CODE}`，如 `SH.600519`、`SZ.000001`、`BJ.830799`）。
* **时间戳规范**：所有表必须包含双时间戳——`ts_event_utc`（事件实际发生/交易所撮合微秒时间戳 `INT64`）与 `ts_ingested_utc`（系统落库时间戳 `INT64`），彻底杜绝回测中的未来函数（Look-ahead Bias）。交易日统一为 `trade_date`（`DATE`, `YYYY-MM-DD`）。
* **量价与金额精度**：
* 价格统一以 **`DECIMAL(12, 4)`**（或回测内存中 `FLOAT64` 配合 `adj_factor` 前后复权因子）存储，命名强制带后缀：`_raw`（不复权）、`_hfq`（后复权，用于回测计算真实收益率）、`_qfq`（前复权，用于前端 K 线展示）。
* 成交量统一换算为 **股数（Shares，非“手”）**，字段名为 `volume_shares`（`INT64`）。
* 成交额统一换算为 **人民币元（CNY，非“万元/亿元”）**，字段名为 `turnover_cny`（`DECIMAL(20, 2)`）。



### 3.2 多源异构数据校验、补齐与故障轮询自愈机制

当东方财富、腾讯行情、新浪财经、同花顺、Tushare/AkShare 传回字段不一致或局部缺失时，由 `02-data-normalizer` 执行 **四步清洗与仲裁协议（Quorum Reconciliation Protocol）**：

1. **Schema 适配器映射（Adapter Mapping）**：每个数据源配置声明式映射表（如将腾讯 `f58` 盘后固定价格成交量自动乘以 100 映射为 `post_volume_shares`；将东财单位“万元”乘以 `10000` 映射为 `_cny`）。
2. **三源多数派投票仲裁（3-Way Quorum Validation）**：
* 实时拉取主源（Primary: 东财/Level-2）、备源 A（Secondary: 腾讯行情）、备源 B（Tertiary: 新浪/同花顺）。
* 若三源最新价满足 $\vert{}\text{Price}_A - \text{Price}_B\vert{} / \text{Price}_A \le 0.0001$，直接采信；若某源偏离超过阈值或时间戳停滞超过 3 秒，立即触发 **数据源降级熔断（Circuit Breaker）** 并剔除异常值。


3. **缺失字段智能补齐（Deterministic & ASOF Imputation）**：
* **可推导字段确定性回填**：若某源缺失 `vwap_cny`（均价），由 `turnover_cny / NULLIF(volume_shares, 0)` 精确计算；若缺失 `turnover_rate_pct`（换手率），结合本地缓存的最新 `float_shares`（流通股本）实时补齐。
* **时序断点插补**：使用 Polars 2.1 原生 `join_asof` 与前向状态保持（Forward-Fill with staleness flag `is_imputed = true`）对齐不同频率的数据流。


4. **自适应多级轮询与健康巡检守护进程（Adaptive Watchdog Polling）**：
* 针对消息面与行情源中断风险，系统内置 `SourceHealthDaemon`：采用 **WebSocket 优先 + 令牌桶自适应 HTTP 轮询（Token-Bucket Polling，盘中 1–3 秒动态抖动防 WAF 封禁，配置多 IP 代理池与 Header 轮换）**。一旦检测到推送延迟大于 5 秒或口径校验失败，前端状态栏实时亮起黄/红灯告警，后台自动无缝切换至备用通道并触发差异补录（Gap Backfill）。

## 四、 全维影响因子挖掘体系：A股微观现实 + 国际宏观 + 消息/情绪/席位/技术四维融合

系统摒弃单一指标选股，建立 **四维实时张量（4D Alpha Tensor）**，通过实时守护进程拉取并经由大模型结构化算子与量化算子联合打分：

### 4.1 第一维：消息面与全球宏观跨市场传导引擎（News & Global Macro Engine）

1. **权威信源多级交叉校验（Multi-Source Cross-Verification）**：
* **Tier-1（定调级，权重 1.0）**：新华社、央行（PBOC）、证监会（CSRC）、发改委/工信部官网、国务院政策吹风会。
* **Tier-2（闪电级，权重 0.85）**：财联社电报（CLS）、东方财富全球快讯、同花顺 7×24、证券时报、上证报。
* **Tier-3（国际映射级，权重 0.80）**：Reuters、Bloomberg、美联储议息声明、美股盘后财报（如英伟达/特斯拉对 A 股算力/果链/机器人板块的直接映射）。
* **去伪与共振校验算法**：任何单一来源的突发利好，在 180 秒内若未获得至少 2 个独立信源交叉印证，标记为 `UNVERIFIED_RUMOR`（权重折半，防小作文诱多）；一旦新华社 + 财联社 + 东财三源共振，立即触发 **毫秒级策略重算中断（Event-Driven Strategy Re-evaluation）**。

## 五、 核心业务双阶段闭环：板块/个股推荐榜 → 个股全维工作台与操作计划

系统界面与核心数据流严格围绕 **“选股（Stage 1） → 个股深加工与买卖执行（Stage 2）”** 展开：

### 5.1 Stage 1：板块推荐榜、火速晋升板块备选池与全市场推荐排序

1. **任意板块点入即享【板块个股推荐榜】**：
* 覆盖申万一级/二级/三级行业及 300+ 实时概念板块。点进任意板块，系统按 **板块内综合推荐分（Sector-Internal Alpha Rank）** 实时排列 Top 10 必看个股，并标注其在板块内的生态位角色：**【空间龙（最高连板）】、【中军容量核心（成交额最大+机构主导）】、【弹性先锋（20cm 创业板/科创板领涨）】、【低位补涨潜伏（技术面突破+估值安全）】**。


2. **【火速晋升板块（Rapidly Rising Sectors）】先手备选池**：
* 传统软件按板块当日涨幅排序，看到时往往已涨停潮无法买入。本系统以 10 秒为步长计算全市场板块的 **资金流入一阶速度 $v_S(t)$ 与二阶加速度 $a_S(t)$**：



$$\text{SurgeScore}_S(t) = w_1 \cdot \frac{\Delta \text{Rank}_S(t, t-5\text{min})}{5} + w_2 \cdot \frac{d^2(\text{NetInflow}_S)}{dt^2} + w_3 \cdot \text{LeadStockLimitUpSpeed}_S$$

* 一旦某板块在 3~5 分钟内排名跃升超过 15 位且龙头股出现倍量点火，系统立即将其置顶推入 **【火速晋升板块备选池】**，并提前毫秒级挑出板块内尚未涨停但盘口异动最强的 3~5 只核心股，供用户第一时间先手介入。

3. **全市场选股总榜（多周期赛道分层）**：
* 选股池按策略属性清晰划分为三大赛道：**超短捉妖池（1~3 日博弈）**、**短线波段池（3~15 日趋势）**、**中长线配置池（1~6 个月产业景气+基本面拐点）**，每只推荐个股均附带四维得分雷达图与推荐证据链。



### 5.2 Stage 2：个股全维深度工作台（Stock Workbench）与做T/网格/持有计划

点击任意推荐个股进入 **个股工作台**（所有数据与状态实时同步至 `stock_workbench_states` 表），工作台一次性完成四大核心任务：

1. **全周期技术面共振透视（Multi-Timeframe Technical Matrix）**：
* **周期联动**：同屏/一键穿透 **分时、1m、5m、15m、30m、60m、日线、周线、月线、年线**。计算 **多周期共振指数（MTF Alignment Score）**——例如月线/周线处于多头主升、日线回踩 20 日均线缩量企稳、30m/5m 出现 MACD 底背离金叉，判定为 **“S级多周期共振买点”**。
* **全量技术算子**：K线形态识别（早晨之星、仙人指路、箱体突破、揉搓线）、MACD（DIF/DEA 斜率、红绿柱面积比、跨峰顶底背离自动连线）、均线缠绕与发散度、量能结构（倍量柱、地量群、分时攻击量比）、筹码分布 CYQ（单峰密集突破、上方套牢峰阻力位、获利盘比例）。


2. **实时消息/情绪/席位联动重算（Live Event-Driven Recalculation）**：
* 盘中后台脚本一旦拉取到与该股或其所属板块相关的最新消息、股吧热度突变或大单异动，自动触发大模型与量化算子重算，**3 秒内刷新工作台上的买卖点价格区间与持有计划**。


3. **动态买卖点与结构化持有计划（Actionable Execution & Holding Plan）**：
* 拒绝模糊的“逢低关注”，直接输出精确到分位的四档执行指令：
* **理想建仓区（Buy Zone）** 与 **突破追击点（Breakout Trigger）**
* **建议仓位上限（Kelly / 波动率目标仓位）**
* **移动止盈目标（TP1 减半仓锁利位 / TP2 清仓目标位）** 与 **硬性止损红线（Stop-Loss，跌破关键筹码峰或 ATR 止损位无条件离场）**
* **预计持有周期与失效条件（Time-Stop & Thesis Invalidation）**




4. **个股专属降本增利引擎：日内做T（Intraday T+0）与自适应网格（Dynamic Grid）**：
* **日内做T引擎（正T / 倒T 实时信号）**：针对已持有底仓（`available_t0_shares` 大于 0）的个股，结合 **1m/5m 箱体上下轨 + 分时 VWAP 偏离度 + 1m MACD 顶底背离 + L2 委买委卖失衡度（Order Book Imbalance）**：
* **正T（先买后卖）**：早盘急跌触及日内支撑位且出现缩量恐慌承接、1m 底背离时，提示利用可用资金买入等量底仓；午后反抽 VWAP 或箱体上沿时卖出原底仓，保持总股数不变，直接降低持仓成本。
* **倒T（先卖后买）**：早盘受消息刺激脉冲冲高偏离分时均线大于 $2.5 \times \text{ATR}_{5m}$ 且伴随股吧高潮、上档大单压盘时，提示先卖出 30%~50% 昨仓，待尾盘或盘中回踩均线时接回。


* **ATR 自适应波动率网格交易（Adaptive Volatility Grid）**：
* 针对震荡上行或箱体盘整股，自动以过去 20 日平均真实波幅（$\text{ATR}_{20}$）与筹码密集峰中枢 $P_{\text{anchor}}$ 构建非对称网格：





$$\text{GridStep}_{\text{buy}} = \max(0.015, 0.35 \times \text{ATR}_{20}/P), \quad \text{GridStep}_{\text{sell}} = \max(0.018, 0.45 \times \text{ATR}_{20}/P)$$

趋势向上时自动放大卖出步长、缩小买入步长（多攒筹码）；严守 A 股 T+1 可用底仓约束，每完成一格配对自动核算已实现降本金额（`realized_cost_reduction_cny`）。

## 七、 国际公认统一记账标准与多基准验证内核（Canonical Accounting & Benchmark Standard）

彻底废除过去不同脚本各自算账的做法。全系统所有回测、模拟盘重放（Paper Replay）、瑞士轮竞赛、做T降本核算，**必须且只能调用 `07-canonical-ledger` 提供的唯一记账内核**：

1. **符合 GIPS（全球投资业绩标准）与 FIFO 复式记账法则**：
* 每一笔模拟或实盘委托必须经过统一的 **订单生命周期状态机**：`PENDING_NEW -> ACCEPTED -> PARTIALLY_FILLED / FILLED / REJECTED_LIMIT_LOCK / EXPIRED`。
* 每日收盘执行 **逐日盯市清算（Mark-to-Market NAV Settlement）**，精确拆分：现金账户（`cash_cny`）、持仓市值（`market_value_cny`）、冻结资金、已实现盈亏（`realized_pnl`）、未实现浮动盈亏（`unrealized_pnl`）与累计摩擦成本（`total_friction_cny`）。


2. **A股真实微观摩擦与制度刚性约束（零妥协仿真）**：
* **全口径税费**：卖出印花税 `0.05%`（万分之五）+ 双边券商佣金 `0.015%`（万1.5，单笔最低 5 元人民币）+ 过户费 `0.001%` + 冲击滑点（按委托金额占当分钟成交额比例动态计算 $\text{Slippage} = \text{Spread}/2 + \eta \cdot \sigma \sqrt{V_{\text{order}}/V_{\text{bar}}}$）。
* **T+1 锁仓铁律**：当日买入的股数记入 `locked_t1_shares`，当日 `available_sell_shares` 严禁包含今日新开仓部分；日内做T卖出量严禁超过昨日结转底仓。
* **涨跌停与停牌流动性锁**：当个股处于一字涨停（`ask_vol_1 == 0` 且封单比大于阈值）时，买单进入排队队列，按真实成交量消耗模型判定能否排单成交，严禁“见涨停价即 100% 买入成交”的虚假回测；跌停板同理严禁虚假卖出止损。


3. **三重基准验证门禁（Triple-Benchmark Gate）**：
任何策略要从回测晋升至前台推荐，必须同时击败：
* **Benchmark 1（宽基基准）**：沪深 300 / 中证 500 / 中证 1000 同期超额收益（Alpha 大于 0）。
* **Benchmark 2（同板块等权基准）**：证明选股能力优于单纯买板块 ETF。
* **Benchmark 3（1000 次同市值/同换手率随机抽样基准 Matched Monte Carlo Baseline）**：剔除运气成分，确保策略盈利率位于随机分布前 5% 分位（$p$ 小于 0.05）。
