# 附件量化方法与论文核查：v3.1 采纳理由及替换规格

审阅日期：2026-11-11（Asia/Manila）。对象为用户附件《粘贴的文本 (1)(20261111-015255).txt》，对照已交付 v3。本文是可并入项目的增补建议；没有运行论文训练、真实行情回测或盈利验证。

## 1 结论与真正增量

附件最有价值的增量不是另起一套平台，而是把若干现有模块细化为可以命名、计算和验证的研究对象：注意力—资金代理背离、板块升温分量、事件锚定 VWAP、成交量价格分布、换手成本分布估计，以及一条显式 ATR 网格 holding 候选。已分别写成 F097—F101 与 S061 的完整目录条目。它们复用既有时点数据、19 维 FeatureKey、统一账户和执行链，不新增独立资金账本。

v3 已有：四维分析、板块榜与快速升温池、盘前/盘中/午间/盘后研究、席位假说、模型数值来源、六种策略职责、组合法、T/网格经济评价、研究联赛、多周期指标、共享特征。不能把这些重复描述计为新增系统能力。新增是细化的算法身份、必要前提、失效条件、验证方案和目录空位。

附件把统计代理直接写成“主力身份”“真实成本”“次日铁律”，把论文方法直接写成已证明的交易效果，以及把研究排行直接写成生产晋级。这些必须替换，原因是它们会改变模型的目标含义与实测口径，不是文字措辞偏好。

## 3 可直接实施的算法规格

### 3.1 F097 注意力—资金代理背离

在同一个已完成窗口 w 内计算：

- A = log(1 + 去重独立作者数 / 交易分钟数) × 看多作者比例。作者封顶、采样覆盖、立场模型及去重规则必须固定版本。此为项目拟定基线，不假冒附件公式已有实证。
- F = 该窗口供应商净流量 / 该窗口成交金额；分子分母使用相同标的、会话和时间范围。`metric_namespace`、来源端点与 `methodology_version` 构成口径身份。
- D = (A−μA)/σA − (F−μF)/σF。μ/σ 来自决策前已完成的冻结校准窗，可按盘中时间桶拟合，避免开盘天然热度较高被误当异常。

必须声明 `min_calibration_windows>=2`、`min_unique_authors>=1`。建议用于第一批试验的样本阈值可取 30/60 个历史窗口和 5/10 个独立作者，但这些只是候选参数；训练期确定，样本外不改。σ 为零/低于声明的数值可分辨阈值、窗口不完整、分母为零或来源方法变更时返回 UNKNOWN，不用任意 ε 把微小分母放大成大信号。

D 的正值只表示两个代理相对其各自历史的方向差。即使各自标准化为方差 1，D 的方差仍是 2−2ρ；不能从 D>2 推导固定概率。新增模型时报告 attention-only、flow-only、combined、无该特征四种消融，并检查收益、换手、方向敞口、来源覆盖与每个交易时段。

### 3.2 F098 板块升温分量

令 r 为升序名次（1 最好），N 为同一冻结母集板块数。N>1 时 q=1−(r−1)/(N−1)，`percentile_gain=q_t−q_prev`。由 20 升到 5 是正向改善。母集改变、概念成分修订或有效板块缺失时，不直接比较旧/新序号；重新建立带版本的可比集合。

对同一方法的累计净流 C，以固定交易时间步长 h 计算 v=(C_t−C_(t−h))/h，a=(C_t−2C_(t−h)+C_(t−2h))/h²。若来源给的是区间净流，先映射到明确区间而非重复当累计量差分。使用“区间净流/区间成交额”的尺度归一变体时，需要另一个定义版本，因为其导数已不是原始 C 的二阶导。

排名百分位改善、资金代理加速度、上涨广度扩散和龙头确认分别输出。冻结训练变换后才可加权，不直接相加“名次/分钟、元/分钟²和一个不明单位的龙头速度”。仅允许向后平滑；不能用居中窗口借未来数据降噪。午休/隔夜/重置/断源都按会话政策处理。10 秒可作为采样候选，不能由此宣称真实 10 秒数据更新、毫秒捕获或 3 秒完整推理。

池状态继续沿用 observing→qualified→actionable 等既有状态机，加入滞回/最短驻留/到期；研究升温得分不能绕过个股买点与账户行动判断。领先性指标应报告：发现相对事件的延迟、误报、可行动比例、成本后的追随结果，而不是只展示成功样例。

### 3.3 技术指标及背离

v3 已在 FeatureKey 记录定义/参数/实现/复权等身份，并在 F074 规定 EMA 初始化及 MACD 柱是否乘 2；这些保持。此次细化四项：

1. 高周期未闭合 bar 使用 provisional 输出，其历史版本不可回填为当时已完成值。
2. 枢轴背离登记左右确认长度、最小间隔、价差阈值、MACD 比较分量、同一复权基准和确认时点。显示线的锚点时间与策略可用时间分别记录。
3. 热身长度、缺 bar、停牌跨期和 EMA seed 固定；图表与策略消费同一已登记输出。
4. 仅当确认所需右侧数据实际可用后才触发；刷新未来数据可以增加后续事件，但不得修改过去已发出的历史信号。

TradingView 官方的 repainting 文档给出 pivot 在右侧 5 根之后才确认却绘回过去的例子；这说明必须区分几何位置与信息可得时间。[VM-S12]

### 3.4 F099 / F100 / F101 三种价格分布对象

| 对象 | 计算/解释 | 必须记录 | 不能声称 |
|---|---|---|---|
| F099 AVWAP | 指定锚点后 Σ成交额 / Σ成交股数，输出价格水平 | 锚点类型与可得时间、范围、会话、原价/复权、成交覆盖 | 某机构或游资真实剩余持仓成本 |
| F100 成交量分布 | 在给定价格 bin 内汇总成交量；bar 内分配需估计模型 | bin、数据分辨率、边界处理、侧向分类、range_id | 当前全体持有人库存分布 |
| F101 换手成本估计 | 例如 q_t=(1−λ_t)q_(t−1)+λ_tg_t，其中 λ∈[0,1]、g 归一 | 留存模型、初始分布、热身、流通股本、公司行动与参数版本 | 精确真实筹码、真实被套盘、假机构身份 |

F078 仍是会话 VWAP 的偏离/收复因子；不能因 F099 新增而删除 F078。F100 的可见窗口属于图表范围：用户拖动视窗会改变显示，策略只能使用冻结明确范围。F101 必须检验参数敏感性与分布守恒；不同供应商 CYQ 不强行视为同一真值。缺历史不能靠一个伪精确“初始筹码全在收盘价”填平。

### 3.5 S061 ATR 自适应库存网格

补齐目录不等于新增账本。S061 属 `holding`，子形式 `grid`，输出 `InventoryOverlayIntent`。基础版本依赖 F075 波动、F018 会话与 F084 流动性；事件 VWAP 或成本密度锚点分别为可选研究变体，避免一个昂贵 CYQ 模块阻塞基本网格。

附件 0.015/0.018 的步长表示 1.5%/1.8%，0.35/0.45 是 ATR 比例参数，全都仅登记 trial。执行前使用有效费用模型检查 proposed size 的两腿佣金/最低费、税、价差和滑点。低买高卖配对成功只是一个结果；未完成卖腿的额外库存、未完成回补的库存缺口和剩余现金都进入同一终点财富比较。重锚形成新版本，并先处理在途订单。

### 3.6 Matched-random 与联赛评价

将可投资池、历史行业/市值/流动性、决策时点、持有期、组合规模、现金、再平衡、换手约束及执行成本写入 BenchmarkDefinition。每次随机候选按同一个成交内核重放，不能拿随机无费用收益与实际有费用策略比较。若某交易日无匹配样本，保留不完整原因，不事后选择容易战胜的对照。

对 B 个可交换零假设模拟，单侧经验 p 可登记为 `(1 + # null_statistics >= observed_statistic)/(B+1)`。1000 次是预算候选；它决定分辨率和模拟误差，不自动证明稳健。该加一约定与 SciPy 随机置换检验文档一致，但本站匹配抽样是否满足可交换假设仍需单独论证。[VM-S15] 时序相关和重叠持有需要时间块设计；若候选经过许多次筛选，单次 p<0.05 不覆盖选择偏差。保留所有 trial、冻结最终验证，或使用满足假设的多重/序贯方法。

指标名称不得混用：IR 是主动收益/跟踪误差；ICIR 是截面 IC 的时序均值/标准差；Calmar 通常将声明年化收益除以绝对最大回撤，零分母须定义为不可计算而非任意大。IR/ICIR 的区分也可与 CFA 和 Qlib 的原始指标定义对照。[VM-S13][VM-S14] 年化频率、负值和样本不足分别列明。所有比率与抽样方案需事前定义，不由最后赢家反推。

## 5 数据/API 影响与验收

不修改 v3 核心 wire schema、account ledger 或 API operation 名称。新候选先登记在统一目录；新增输入合同写成 `required_contract_not_yet_registered`，不得冒充已存在数据库列。正式落地时把候选的 definition/parameter/dependency/manifest 注册到现有 feature/analysis/research 存储接口，经既有发布与工作台路径消费。

最小新增语义合同族：AttentionWindow、ComparableFlowWindow、FrozenCalibration、SectorRankingWindow、SectorFlowWindow、SectorBreadthLeadership、AnchorDefinition、AnchoredTradeWindow、VolumeProfileWindow、VolumeAllocationPolicy、TurnoverCostModel、PriceVolumeHistory、GridDefinition。它们是需要定义并绑定的输入/产物规格，不是 13 张必须创建的表。

已做的验证只有目录结构：5 个新因子、1 个策略，10 项机械检查通过；没有实测行情或收益。最先实现的经济判别应是：RFD 真假增长/缺值测试，Surge 方向/母集/时钟测试，AVWAP 手算，Profile 总量守恒，CYQ 归一/公司行动/敏感性，Grid 与相同初始底仓和现金的共同终值比较。只有这些明确问题仍存在才继续扩大测试，不以无意义测试数量宣称可靠。
