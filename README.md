# Pulse · 用"做实验"的方式炒 A 股

> 一个只做沪深主板的 A 股研究工作台。它每天收盘后自动选股、给出买卖计划；盘中录行情、抓新闻、盯持仓。
> 它和大多数炒股工具最大的不同是：**每一条"战法"都要先写下检验标准，再用当时能拿到的数据回测，最后在真实的后续行情里接受检验。**
> 不管成功还是失败，都记进公开的[研究账本](docs/research/ledger/README.md)，目前已有 100 多条实验。

**本项目只用于研究和学习，不构成任何投资建议。** 历史回测不代表未来收益。

---

## 为什么值得一看

网上的"必涨战法"很多，真正检验过的很少。Pulse 把常见说法逐条放进同一套严格的回测里，下面是一些实测结论：

| 常见说法 | Pulse 的检验结果 |
|---|---|
| 打板、接力龙头能赚钱 | 扣除"小盘、高波动"的风格因素后，打板接力类仍然**跑输**同类股票 1.5–3.7 个百分点（E062） |
| 超跌就会反弹 | 单靠超跌买入不显著；**有利空公告的超跌股之后更差**（E070） |
| 涨得最猛的继续涨 | 近 5 日相对行业涨幅最高的 10%，之后 5–10 日**稳定跑输**同类股票（E070） |
| 美股大跌后，A 股第二天反弹 | 在 2010–2023 年 213 次事件里**不成立**；A 股的下跌在开盘集合竞价时就已经消化掉了（E084） |
| 美联储议息那天别急着买 | **成立**。2010–2023 年 112 次议息，反应日开盘买入当天平均比平常差 0.26 个百分点（p = 0.006，E083） |
| 选股分数排第一的最好 | 分数真正的用处是**避开最差的 20%**，而不是挑出最好的那几只（E071、E079） |

每个结论都有对应的预注册文档、代码和数据口径，见 [`docs/research/`](docs/research/)。


## 现在只有一个版本：Pulse 3

旧版（`backend/`、`frontend/`、`scripts/`）已在 2026-11-25 退役，代码从仓库删除，历史仍在 git 里可查。全部功能都在 [`pulse3/`](pulse3/)，说明见 [`pulse3/README.md`](pulse3/README.md)。

- **一份契约管全部**：每个接口的输入输出都由同一份 JSON Schema 定义，前端类型由它生成。
- **只追加、按时点**：每份数据都带"何时可知"的时间戳，修订只追加新版本，不覆盖旧数据，回测只用当时能拿到的数据。
- **自己录数据**：盘中 60 秒快照（全市场每分钟一张，热门股每 20 秒一次）、7×24 新闻、宽基 ETF / 指数 / 期货、日线与指数、龙虎榜席位，全部由 Pulse 3 自己的录制器按每个网站每秒最多 1 次请求获取，被拦截立即停止，不重试。

## 它每天在做什么

**盘中**（交易日 09:10 起）
- 全市场分钟快照、热门股 20 秒快照、集合竞价、涨停封单与炸板；宽基 ETF、指数、股指期货。
- 7×24 新闻按规则判断利好利空和影响范围；规则判断不了、又涉及持仓或观察股的，交给大模型（只用 gpt-6-luna，每天有调用上限）。对照持仓分 P0 / P1 / P2 告警。
- 盘中快照每 5 分钟更新一次可操作性；午休和收盘后自动跳过。

**盘后**
- 日线、指数、行业成分自动更新；融合选股分数、冻结主书与影子账本、前向监控、纸面回放。
- 龙虎榜席位、资金流、日历事件。
- 预注册实验的前向记录：E095–E099（竞价、主动买卖、龙头带动、机构席位、拉萨席位）、E100（联网大模型，暂停中，等成本确认）。

**网页**：市场总览、选股排名与买卖计划、战法库、问句选股、研究台账、数据健康等。只监听本机端口，通过 SSH 隧道访问。

**给 AI Agent 用**：`/llms.txt`、`/v1/agent/manifest` 和只读 MCP 端点 `/mcp` 由同一份能力清单生成。

## 研究纪律（Pulse 的核心）

1. 先写预注册（假设、样本、检验方法、通过标准），用户"定稿"后冻结并记下 sha256，之后改任何设定都算新实验。
2. 只用当时可知的数据（PIT），次日开盘成交，一字板买不到就放弃。
3. 成功和失败都写进[研究台账](docs/research/ledger/README.md)，不删除。看过的数据只做稳健性复核，确认靠之后的新数据。

## 部署

服务器上由计划任务运行（`pulse3/deploy/windows/`）。网页服务只监听本机端口，不对公网开放。

## 数据诚实性

- 每个接口响应都带数据来源、截止时间和覆盖率。缺失的数据显示为 `—`，不填 0，也不估算。
- 回测按日线计算：次日开盘成交，一字涨停买不进就放弃，T+1，跌停封死顺延卖出，按 100 股整手。
- 已知局限写在各实验的预注册和台账里。
