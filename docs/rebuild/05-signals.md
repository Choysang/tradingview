# 05 · 四个信号面与影响因素

> 本卷回答：影响 A 股的因素有哪些、各自怎么观测、在平台里用来做什么；消息面、情绪面、资金面、技术面各自怎么采集、怎么分析、产出什么。
> 四个面的产出统一成一种记录（信号），供选股、个股买卖点、持仓告警共用。

## 1. 统一的信号模型

四个面之间、信号与策略之间只通过一张表联通：`sig.signal`。

```text
Signal
  signal_id, version
  subject_type      INSTRUMENT | SECTOR | MARKET
  subject_id        instrument_id / sector_id / "CN"
  plane             NEWS | SENTIMENT | FLOW | TECHNICAL | FUNDAMENTAL | MACRO
  name              规范名，例如 "seat.retail_cluster_buy"、"heat.z20"、"tech.macd_bull_div"
  value             数值，或枚举
  as_of             信号描述的时刻
  available_at      最早可被决策使用的时刻
  horizon_sessions  信号预期起作用的交易日数
  usage             RANK | VETO | RISK | POSITION | ALERT | DISPLAY   # 允许它影响什么
  evidence_tier     VERIFIED | TESTING | UNTESTED | REFUTED           # 来自策略登记库
  evidence_refs     指向原始事实的引用（消息簇、龙虎榜行、K 线区间）
```

`usage` 的含义：RANK 进入排序打分；VETO 否决买入；RISK 风险标记与排序惩罚；POSITION 调整组合仓位系数；ALERT 触发告警；DISPLAY 只展示。

两条硬规则：

1. **`usage` 是权限，不是建议。** 一个信号能不能进入排序、能不能否决买入、能不能只用于告警，由产出它的策略的状态决定，对应关系只有一张表（06 卷第 5.1 节），策略运行时强制执行。
2. **每个信号都能追到原始事实。** 界面上任何一个标签、分数、告警，点开都能看到它依据的那条消息、那行龙虎榜、那段 K 线。

## 2. 影响因素全集与用途

调研整理了 10 层共 165 项因素（完整清单见 09 卷附表 A；其中发布时点与数据源多为调研员的记忆，接入时逐项核对）。平台按“这类因素能被证据支持到什么程度”分配用途：

| 层 | 代表因素 | 观测方式 | 默认用途 | 依据 |
|---|---|---|---|---|
| 国内宏观 | CPI、PPI、PMI、社融、M1、工业企业利润、地产数据 | 财经日历（预期值与实际值） | 仓位、行业映射、展示 | 台账 E073：没有哪一类宏观事件在两段时期都放大波动；方向未过多重检验 |
| 货币与流动性 | 公开市场操作、LPR、准备金率、DR007、国债收益率、汇率 | 央行与货币网、行情 | 仓位 | — |
| 政策与监管 | 重要会议、产业政策、减持与退市规则、国家队、印花税 | 官方源、事件抽取 | 行业映射、仓位、展示 | 国家队入场 3 年约 5 次，样本不足以检验（本项目闭环评审） |
| 资金面 | 两融、宽基 ETF 份额与放量、大宗、解禁、增减持、回购、龙虎榜 | 交易所披露、行情 | 个股否决、风险、短线排序候选 | 见第 5 节 |
| 外盘与跨市场 | 美股、中概、A50、恒生科技、美债、美元、商品、VIX | 行情 | 开盘风险提示、行业映射 | 台账 E072：隔夜信息在集合竞价里已定价，开盘后既无延续也无反转 |
| 行业与产业 | 产品价格、产业事件、海外龙头财报 | 行业报价、事件抽取 | 行业映射 | — |
| 公司层面 | 业绩预告、分红、重组、减持、质押、立案、问询、订单、调研 | 公告 | 排序候选；利空类一律否决或告警 | 台账 E070：有利空公告的超跌股之后继续跑输 |
| 市场结构与情绪 | 涨跌停家数、连板高度、炸板率、涨停溢价、成交额、拥挤度、基差 | 自算 | 仓位、展示；不做入场门 | 台账 E018：情绪闸门无改善 |
| 日历与季节 | 财报季、交割日、长假、议息日 | 日历 | 仓位、风险 | 台账 E083：议息反应日开盘偏弱（留出样本显著） |
| 交易制度 | T+1、涨跌停、竞价、盘后定价、风险警示、退市、异常波动监管 | 规则表 | 撮合约束、个股否决、告警 | 07 卷第 3 节 |

三条分配原则，直接写进信号登记：

- 宏观、货币、跨市场、日历类只影响**仓位与行业映射**，不进入个股打分。依据：本项目所有“事前判断大局再选股”的尝试都输给固定方案，而“看自己的净值降仓”有效（E006、E042、E044、E036）。
- 解禁、减持、立案、问询、退市风险类只做**否决与告警**，不做正向排序。
- 主力资金流向、人气榜、股吧热度、搜索指数默认**只展示**或作**反向过滤**；想让它们进入排序，必须先过前向门槛。

## 3. 消息面

### 3.1 信息源分层

| 层 | 是什么 | 首选 | 作用 |
|---|---|---|---|
| T0 官方一手 | 交易所与巨潮公告、证监会、央行、统计局、国务院及部委 | 巨潮、沪深北交易所、各官网 | 事实的最终依据 |
| T1 通讯社与四大证券报 | 新华社、央视、人民日报、中证报、上证报、证券时报、证券日报 | 各官网 | 给快讯做权威背书，不求快 |
| T2 财经快讯 | 财联社电报、东财快讯、同花顺 7×24；备选金十、华尔街见闻、格隆汇等 | 现有三源 + 至少一个备选 | 速度 |
| T3 自媒体与社区 | 股吧、雪球、淘股吧、热榜 | 有榜单接口的优先 | 只做热度与观点，不做事实确认 |

宏观类是定时事件：由财经日历驱动，到点才轮询对应官网。完整的源清单（约 60 个）与各源的访问方式、可得性见 09 卷附表 B；其中除现有三源外的可用性都未实测，接入顺序见 08 卷。

### 3.2 一条消息怎样才算“已确认”

满足任一条即为已确认：

1. T0 原文命中。
2. T1 命中，且 30 分钟内至少一个独立的 T2 源跟发。
3. 两个独立的 T2 源在 15 分钟内报道同一件事，且主体与关键数字一致。

只有单个 T2 源或只有 T3 的，标为“待确认”或“传闻”。**未确认的消息不能触发否决与告警以外的任何动作**，在排序里的权重上限由登记库限定。

“独立”的定义：正文写明转引同一上游的两个源只算一个。出现“澄清、辟谣、更正、撤回”时，归入原事件线，原事件降级并通知下游撤销告警。

这套规则直接回应“消息要经过新华社、财联社、东方财富等多源校验”的要求。现状三个源各自去重，没有任何交叉确认（01 卷 #40）。

### 3.3 管线

```text
采集 → 规范化 → 去重与聚类 → 实体链接 → 事件分类 → 影响评估 → 已反映度量 → 路由 → 前向日志
```

| 阶段 | 产出 | 方法 | 失败时 |
|---|---|---|---|
| 采集 | 原始条目（发布时刻与收到时刻分开） | 适配器（04 卷） | 源健康降级并告警 |
| 规范化 | `intel.item` | 规则：清洗、去广告、标题标准化 | 进隔离区 |
| 去重与聚类 | `intel.cluster`：事件簇、首发源、跟发源、是否重组旧闻 | 内容哈希、局部敏感哈希、向量近邻，在线单遍归簇；阈值用我们自己录制的电报标注后校准 | 不确定时新建簇，宁可多不可错并 |
| 实体链接 | 主体与角色（本体、上游、下游、竞争对手、同概念） | 证券简称、曾用名、别名、产品词典优先；向量重排；低置信度才交给大模型 | 链接不上则不向下游传 |
| 事件分类 | 事件类型与依据句 | 规则优先；本地小分类器其次；低置信度才用大模型 | 输出校验失败重试一次，再降级为“未分类” |
| 影响评估 | 方向、范围、级别、新颖度、可核对性 | 大模型只输出枚举值与依据句 | 没有依据句的判断整条作废 |
| 已反映度量 | 消息前的异常收益、成交量倍数、已反映程度 | 确定性代码：以事件簇首次可见时刻为零点，对比此前的价格与成交 | 缺行情记为未知 |
| 路由 | 信号、标签、告警 | 确定性规则 | 不满足门槛只记录 |
| 前向日志 | 每条判断的完整快照与到期评分 | 定时作业，不可回改 | 缺数据标为待定 |

设计依据：

- **规则优先、大模型兜底。** 现有的告警已经是这个结构；在没有密钥的条件下回放 1,199 条消息，判定全部来自规则，另有 158 条本应交给大模型的被跳过（台账 E075）。
- **运行位置与延迟。** 管线跑在 `pulse-stream` 进程里，与批作业分开（03 卷第 5.1 节）。目标：规则路径从收到到告警不超过 10 秒，走大模型的不超过 30 秒。
- **新颖度是一级字段。** 文献显示近一半的文章内容陈旧，重组旧闻会引发更大的波动和之后的反转（09 卷）。
- **“已反映程度”必须记录。** 本项目 11-04 的案例里，快讯“午后直线拉升”发出时行情已经启动；看到消息再追，买到的是结果。
- **方向由价格确认。** 同一个案例里，美股期货下跌而 A 股反向大涨。大模型给出的方向只是先验，路由规则要求跨市场价格与市场广度同向才升级告警。

### 3.4 大模型的输出契约

大模型只允许输出下面这些字段，全部是枚举、引用或短文本：

| 字段 | 取值 |
|---|---|
| `event_type` | 事件类型表中的编号，或“未知” |
| `entities[]` | 证券代码、角色、置信度 |
| `direction` | 利好、利空、混合、中性、不明 |
| `scope` | 市场、行业、概念、公司 |
| `tier` | 国家级、监管、公司公告、媒体报道、传闻 |
| `novelty` | 首发、更新、重复、重组旧闻、未知 |
| `verifiable` | 是否有可核对的公告或文号 |
| `evidence[]` | 原文引用及其字符位置（必填） |
| `uncertainty` | 低、中、高 |
| `summary` | 不超过 60 字，仅用于展示 |

大模型**不输出**分数、排名、涨跌幅预测、目标价、买卖建议、已反映程度。这些由代码计算。每次调用记录模型标识、提示词版本、输入快照、输出、耗时、费用。

事件类型表的初始版本有 66 类（09 卷附表 C），每类带默认方向、影响对象范围、典型持续期与默认用途。默认方向只是冷启动先验，由前向日志逐类校准。

### 3.5 消息怎样影响策略：三级权限

| 级别 | 允许做什么 | 进入条件 |
|---|---|---|
| 一级：标签与解释 | 在个股页、推荐卡片、复盘里展示；不改变任何排序 | 默认 |
| 二级：否决与告警 | 利空类事件对持仓发告警；对新买入做否决 | 事件已确认，且该事件类型的规则通过抽检。告警分两种：对持仓的已确认事件发出的“事实提醒”只是转述事实，不依赖收益假设，不受策略状态限制；由事件触发的**否决**必须对应一个候选及以上状态的否决器（上线时只有公告类利空，06 卷附录 A.10） |
| 三级：排序特征 | 作为特征进入确定性打分 | 该事件类型积累了足够的前向样本，扣成本后的风格匹配超额为正，且匿名对照与随机映射对照不削弱结论 |

盘中消息默认只用于持仓保护与风控，不用于追买。依据：T+1 下盘中买入必须承担隔夜（本项目闭环评审记录的 2026-11-06 主板等权开盘跳空为 −2.38%）；台账中所有追涨类规则为负。

### 3.6 评测与防泄漏

- 历史检验只用自建的时点语料：只检索收到时刻不晚于决策时刻的条目。
- 实名卡片与匿名卡片各判一次作对照。匿名只是对照，不是证据：文献显示模型能凭极少上下文还原被遮蔽的公司（09 卷）。
- 随机映射对照：把事件随机配给无关股票，结果应为零。
- 联网搜索类判断只能前向记录，永不回测（搜索工具没有日期过滤）。
- 晋升只看所用模型训练截止日之后的前向样本。
- 每周抽检，错例进入标注集；固定的金标集每日回归，监控模型漂移。

## 4. 情绪面

情绪面分两部分：市场自己的行为数据，以及人群的讨论。

### 4.1 市场情绪（自算）

涨停与跌停家数、连板高度与梯队完整度、炸板率、昨日涨停股今日表现、上涨家数占比、成交额相对其均值、新高新低数。全部用时点正确的口径计算：

- “昨日涨停溢价”= 昨日收盘封住涨停的股票今天的平均涨幅，名单取自昨日的 `mkt.limit_pool`。
- “晋级率”= 昨日 N 板的股票今天继续封板的比例，分母取自昨日名单。

现状这两项在实时模式下的算法是错的（01 卷 #1）。

用途：市场状态的“情绪轴”、仓位参考、复盘。不作为入场门。

### 4.2 社区热度与观点

| 能力 | 做法 |
|---|---|
| 热度 | 对每只股票，取各平台的帖量、阅读、人气排名、关注数，换算成“相对自身 20 日基线的 z 分数”；剔除涨停日、上榜日的机械放大；另存“热度与价格背离” |
| 采样节奏 | 盘前（隔夜帖量与热榜）、盘中（榜单排名变化，15 分钟一次）、盘后（当日总量与复盘帖） |
| 观点抽取 | 对热度异常的股票，抽取评论区的方向、理由、目标价、期限；大模型只做抽取 |
| 观点对账 | 每条观点到期后按实际走势评分；发言者的信誉分用收缩估计，样本少的不显示结论 |
| 与平台判断并排 | 个股页上并排显示“社区在说什么、历史上这类说法对不对、平台四个面的判断是什么”，不合成一个数 |

默认用途是**反向过滤与风控**，不是正向跟随。依据：

- 多项中文市场研究指向同一个模式：关注度升高的当日价格同向，之后反转（09 卷，摘要级证据）。
- 散户小账户的交易方向负向预测收益（09 卷）。
- 本项目的追涨类实验全部为负。

数据可得性是现实约束：股吧抓取目前大多失败，雪球需要登录令牌，其余平台没有稳定接口。平台不绕过登录与验证码。第一版只接入有榜单接口的来源，其余低频采样或暂缺，并在数据健康页如实显示。

## 5. 资金面

### 5.1 龙虎榜席位画像

目标：给每个营业部席位建立可统计、时点正确的风格画像；选中的股票上榜时主动给出分析。

- **席位实体**：`ref.seat` 加别名表与有效期，处理更名与搬迁。市场流传的游资昵称单独存放、带来源与“未经证实”标记，不进入任何统计。
- **席位类型**：机构专用与陆股通专用是匿名资金池，只做池级统计；量化候选席位（上榜频次高、买卖同榜比例高）单独标记；其余为普通席位。
- **画像指标**：上榜次数、次日开盘溢价、第 3 根收盘收益、风格匹配超额、次日出现在卖方的比例、持有天数分布、偏好的市值与连板位置、买卖同榜比例、与哪些席位经常同榜。
- **统计方法**：只统计已到期的交易；到期日按该股自己的 K 线计；剔除次日开盘涨停买不到的事件并扣成本（现状没有，01 卷 #23）；样本少的席位向总体均值收缩（经验贝叶斯）；少于 5 次不显示结论，5–30 次只显示带区间的收缩值，30 次以上才允许进入规则；标准误按交易日聚类。
- **组合特征**：同一天同一只股票被同类席位共同买入的数量；买卖同时上榜。

已有证据与用法：

| 席位类型 | 证据 | 默认用法 |
|---|---|---|
| 散户集中的营业部（拉萨的若干家）共同买入 | 本项目实测：三家以上共买，次日开盘买入后 5 日 −2.52%（t −9.5），10 日 −3.84%。媒体报道这些营业部是线上个人账户的归集地（09 卷） | 风险标记；持有该股时告警；对新买入否决 |
| “一日游”席位 | 国内研究用账户级数据发现资金优势账户炒作并于次日抛售，披露席位可识别此类账户（09 卷，摘要级） | 风险标记 |
| 机构净买入 | 未查到严格的公开检验；本项目尚未单独验证 | 候选，进入联赛待检 |
| 各家知名游资席位 | 没有任何公开论文或研报对单个席位做过严格的后续收益检验（09 卷） | 只展示画像；是否跟随由前向检验决定 |

用户的直觉“不同营业部对应不同打法”在平台里的落地方式是：画像负责客观描述，席位出现在所选股票的榜单上时，个股页给出“这类席位历史上之后怎样”，并把它接入否决与风险规则；正向跟随需要证据。

## 6. 技术面

### 6.1 定位

台账的结论很明确：153 条技术规则（两轮分别 75 条与 78 条）作为独立买卖点，在真实成交仿真下没有一条通过；但量价信息作为排序特征有效（E003、E033、E058、E004）。所以技术面在平台里有三个角色：

1. **排序特征**：换手、波动、反转、量比、位置等进入特征面板，由融合打分使用。
2. **风险告警**：放量破位、异常换手、乖离过大等用于持仓保护。
3. **个股工作台**：完整的图表与指标展示，以及由“操作策略”给出的买卖点；每个买卖点带证据等级，并在联赛里被持续检验（06 卷）。

### 6.2 指标与形态库

| 类别 | 内容 |
|---|---|
| 趋势 | 多周期均线、均线排列、MACD、趋势线、通道 |
| 动量与超买超卖 | KDJ、RSI、乖离、涨速 |
| 波动 | 布林带、ATR、历史波动、振幅 |
| 量能 | 成交量均线、量比、换手、量价背离、天量地量 |
| 位置 | 距 N 日高低点、相对强度排名、缺口 |
| 形态 | K 线组合、平台突破、旗形、杯柄、双底、头肩；每条形态写明省略了哪些条件 |
| 结构 | 分型、笔、中枢（必须逐日增量计算，禁止在整段序列上回看后再标注） |
| 筹码 | 由换手估算的成本分布，界面标注为估算 |
| 多周期 | 周线、月线由日线重建；一周的数值从下一周第一个交易日起才可用 |
| 涨跌停专属 | 首封与末封时刻、封单额、封成比、炸板次数、连板数 |

每个指标是一个注册的纯函数，声明输入列、参数、预热期；预热期内输出空值。所有指标自动接受截断测试。“禁止整段回看”一条的依据是台账 E061：缠论三买的超额完全来自在全序列上计算分型造成的前视。

指标参数在前端可调，调参后的重算在后端完成并缓存；前端不自己计算任何影响判断的数值。

## 7. 市场状态、板块强度与预选池

### 7.1 市场状态五轴

指数趋势、广度、风格（大小盘）、情绪、题材集中度，五个轴分别估计、分别展示，不合成一个开关。依据：单一的“熊市模式”无法表达“大盘弱而某个题材在扩散”（设计 1.0 评审）；台账显示按市场状态缩放仓位不如按账户净值降仓（E044 对 E036）。

状态用于：仓位参考、策略的适用条件标签、复盘。**状态不用于选择买哪一只。**

全平台只有这一份状态定义。现状有 8 处各算一遍（01 卷第 4 节）。

### 7.2 板块强度与升温

板块成分一律取时点正确的口径（04 卷 `ref.sector_member`）：行业用申万带进出日期的成分；题材用每日存档的成分与当日涨停原因。

| 指标 | 定义 | 用途 |
|---|---|---|
| 涨停占比 | 板块内涨停家数 ÷ 成分数 | 强度（核心） |
| 广度 | 板块内上涨家数 ÷ 成分数 | 强度（核心） |
| 成交额占比的变化 | 板块成交额占全市场的比例，N 日变化 | 升温 |
| 相对强度加速度 | 近 N 日相对强度 − 前 N 日相对强度 | 升温 |
| 梯队完整度 | 各连板层级是否都有、最高板数 | 强度 |
| 持续性 | N 日内进入强势榜的次数 | 持续性 |
| 拥挤度 | 换手率的历史分位 | 减分项 |

调研没有找到能直接证明“哪几个指标组合最有效”的公开样本外研究，所以以上权重都作为可调参数登记，由前向记录校准（09 卷）。

**升温预选池**（“火速晋升板块”）：当某板块的升温分在 N 日内的变化超过阈值时触发；触发当刻冻结板块内的候选名单与全部指标快照，写入不可变记录。之后每天对账“触发后 1、3、5、10 日板块与候选的表现”。冻结快照是为了防止事后改标签。

### 7.3 板块内的角色与推荐榜

每个板块页给出该板块当前最值得关注的几只股票。做法分两步：

1. **先打角色标签**（可计算的规则，阈值待回测）：
   - 龙头：板块内连板数最高；并列时取最早封板者。
   - 中军：板块内流通市值靠前、相对强度为正、未封板。
   - 跟风：当日涨停或涨幅居前，但封板晚于龙头、连板数低。
   - 补涨：板块内前期未涨、当日首板。
2. **再在每个角色内分别排序**，不混排。排序因子：板块内相对强度分位、融合分、流动性、可买性（是否一字板、封单强度）；风险惩罚：炸板次数、解禁临近、立案与退市风险、席位风险标记、过热（5 日行业调整涨幅位于前 10%）。

诚实的边界：“买龙头优于买中军优于买板块 ETF”没有查到公开实证；本项目对“主线跟随”用无前视的行业口径回测是负的（经验卡）。所以板块推荐榜上线时证据等级是“未检验”，每一期榜单冻结存档并自动对账，积累前向证据后才能升级。

## 9. 初始默认参数

下列数值是第一版的默认值，全部登记为可调参数；它们是设计起点，不是已被证据选中的最优值。任何改动都要登记，并由前向记录校准。

### 9.1 市场状态五轴

| 轴 | 定义 | 取值 |
|---|---|---|
| 指数趋势 | 上证指数相对 60 日均线的位置；60 日均线的 20 日斜率超过 ±2%；取最近 5 日的众数防抖 | 上行、震荡、下行 |
| 广度 | 主板股票里收盘站上 20 日均线的占比 | 高于 55% 为强，低于 45% 为弱 |
| （辅助，不单列为轴）成交额水平 | 全市场成交额的 20 日均值 ÷ 120 日均值 | 高于 1.15 为增量，低于 0.85 为缩量，其间为存量；与指数趋势一起展示 |
| 风格 | 中证 1000 与沪深 300 的 20 日涨幅之差 | 超过 ±3 个百分点为小盘或大盘占优 |
| 情绪 | 涨停家数 5 日均值相对其 120 日均值的 z 分数，结合 3 日变化 | z 低于 −1 为冰点；z 为负且回升为修复；z 高于 1 为高潮；z 为正且回落为退潮；其余中性 |
| 题材集中度 | 当日涨停股里，涨停数最多的 3 个板块所占的比例 | 高于 50% 为有主线，低于 25% 为无主线 |

前四行的阈值沿用旧系统的市场周期规则，情绪一行沿用旧研究流程里的定义。台账显示这些状态在转折点有滞后，所以它们只用于展示、仓位参考与事后归因（第 7.1 节）。

### 9.2 板块升温与角色
