## 2. 五个模块：怎么做、数据从哪来、和原要求的差别

### M1 实时电报 + 60 秒盘口脉冲 + 1 / 3 / 5 分钟评论交叉验证

- **流程**：收到电报即生成事实卡（不等模型、不等评论），相关股票先进 `WATCH`。60 秒盘口脉冲和 1 / 3 / 5 分钟评论快照各生成一个 `ReactionWindow` 版本。**只有 `cross_validated` 为真，消息类策略才允许输出最终受益 / 承压标的、发出 `FIRED` 买入信号。** 这条按你的要求执行。
- **和原要求的差别**：事实卡和"待验证"的受益候选照常立即显示，只是不能触发买入。原因：设计 1.1 第 5.1 节指出等待本身有成本，"立即 / 30 秒 / 1 分钟 / 5 分钟"哪个更好要用实验回答（设计 1.1 的 E02、E03）。门槛保留，同时记录不加门槛的影子结果，两者在同一成交规则下比较。
- **盘口脉冲**：用录制器的 10 秒快照。成交额增量、外盘减内盘（主买代理，不称"主力"）、相对行业的超额涨幅。前提是相关股票在 60 秒内处在 10 秒网格上，而现在热点池外的股票只有 60 秒一次。**需要改录制器**：消息模块写一个 `watch.json`，录制器每轮读取，把相关股票加入 10 秒网格 10 分钟。改动小，部署前要你同意。
- **数据源（待探测，未接入）**：
  - 财联社电报：网页有公开的电报列表接口，不是官方开放接口，要限速，被拒即停。
  - 同花顺 7×24：同样是网页接口。
  - 东方财富股吧：公开页面可读。
  - 韭研公社：大部分内容可能要登录，不做登录、不绕过限制，取不到就在卡片上标"覆盖缺失"。
  - Tushare `news` / `major_news`：需要单独的新闻权限，适合历史回补，不适合首发。
- **两个时钟**：窗口同时记原发锚点（`ORIGIN`）和本系统首见锚点（`FIRST_SEEN`）。交易只用首见锚点。

### M2 首板簇预警 + 1进2 / 2进3 提前漏斗

- **规则**：同一关系键（地域、地方国资、细分概念、行业）在 11:30 前出现 3 只以上首板即建簇（`clusters`）。次日 09:25–09:45 对簇内股票跑漏斗（`funnel_ok`）：地方国资或并购重组属性、自由流通市值 15~60 亿、竞价高开 3%~7%、竞价稳固、率先换手封板。
- **和原要求的差别**：
  - "9:20 撤单率低"在 Level-1 快照里观测不到：9:20 后不能撤单，9:20 前的撤单看不到。改用录制的 09:19:50 → 09:20:05 → 09:25 匹配价量是否稳住（`auction_firm`），不叫撤单率。
  - 15~60 亿、3%~7% 按候选参数处理。E038 里同类数字在日线上没有通过，这次用 11-02 起的盘中录制数据前向检验。
- **数据缺口**：
  - 公司注册地、实控人类型：巨潮公司资料，或 Tushare `stock_company`（需要 Token），要按日期保存。
  - 自由流通市值：Tushare `daily_basic.free_share`（需要 Token）。没有 Token 时这一项是"未知"，漏斗不放行，不拿流通市值顶替。
- **阶段**：P2，地域和国资数据到位后开始。

### M3 真假炸板五维判别（升级 S1 / S3）

- **规则**（`break_step`）：持仓涨停打开后每 10 秒判一次。
  - 良性分歧：在 VWAP 上方、同题材至少 2 只低位股仍封死、14:20 前、催化未落地，四项同时成立才算，此时压住卖出信号。
  - 立即卖出：跌破 VWAP 连续 90 秒，或板块集体跳水。卖出优先于良性判断。
  - 回封后恢复监控。退出一旦发出不撤回。
  - 任何一项是"未知"都不算良性。
- **约束**：只卖 T+1 可卖股份（`inventory.reserve_sell`），当天买入的股份不能触发卖出。
- **检验**：用"固定同一批入场、只比较卖法"的规程（设计 1.0 的 E17、设计 1.1 的 E10），和"开板即卖""固定持有"对比。
- **数据**：VWAP（快照第 51 位）、10 秒快照都已在录制。"低位伴生股"需要题材成员表（带日期的申万已有，概念待补）。"催化未落地"来自 M1 的事件状态，没有就是未知。
- **阶段**：P1，状态机已写好；接纸面账本后开始前向记录。

### M4 盘后博主股性库 + 次日 09:25 预期差

- **规则**：
  - 每位作者只计最新一条观点；条件式观点（"若竞价转强"）不投票。
  - 至少 3 位独立作者、三分之二同向才算共识（`consensus`）。
  - 09:25 竞价与共识对比（`expectation_gap`）：
    - 昨晚看衰、今早高开 2% 以上且竞价量超过昨日竞价，标为超预期买点候选（B1）；
    - 昨晚看好、今早高开不到 1%，标为兑现陷阱；
    - 其余或数据不全，不出信号。
- **股性标签**：需要 3 位以上独立作者确认才写入。同时按设计 1.1 第 10.2 节，把股性换算成统计特征（跳空回补、触板回封、开盘 30 分钟与后续走势等），两者对照检验。
- **数据缺口**：作者原帖不少是图片（设计 1.1 核实过"湖南人"的近期原帖），需要 OCR。要建作者登记表，作者能力分项统计。
- **时点**：竞价结果最早 09:25:05 可用。录制器的竞价加密网格每 5 秒一拍，覆盖到 09:25:10。
- **阶段**：P2。

### M5 内存实时状态 + WebSocket 推送 + 一屏四区界面

- **后端**：
  - 盘中状态放在决策进程的内存环形缓冲里，通过 WebSocket 推增量（带 `event_id`、游标、`data_as_of`、`expires_at`），断线后按游标补齐。
  - 落盘走后台队列。数据库仍用嵌入式 DuckDB 单写进程，不上 PostgreSQL。
- **录制器与决策进程**：两个进程分开运行，录制器不随网站重启。录制器通过本机回环把快照推给决策进程，同时照常写文件。
- **"0 时延"改成分段 P95 目标**（设计 1.1 第 13.4 节，未压测）：
  - 收到原文到事实卡可见 ≤1 秒；
  - 缓存关系匹配 ≤300 毫秒；
  - 快速模型首判 ≤15 秒；
  - 行情到动作意图 ≤100 毫秒；
  - 推送到页面 ≤500 毫秒。
  来源本身的延迟单独测，不算进本地指标。
- **四区界面**：
  - 顶部：市场温度计。按指数、广度、风格、情绪、题材分别显示，加最高板。
  - 左区：电报事实卡，以及 1 / 3 / 5 分钟交叉验证状态和覆盖平台。
  - 中区：首板簇、1进2 / 2进3 梯队、买点触发池。
  - 右区 / 底区：持仓炸板状态机，以及昨晚作者预期与今早竞价对照表。
- **阶段**：P1 先做后端内存状态、推送和事实卡；四区页面随 M1–M4 的数据到位逐块点亮。

## 4. 事件日历与海外映射（第六个模块，2026-11-02 补充设计）

依据《A 股事件日历与海外市场映射 功能设计补充》（13 页）和候选种子（18 条，`docs/research/seeds/calendar_seed_2026-11-02.json`）。

- **契约**（`contracts/calendar.py`）：每个事件的三个时间分开存，即日程首次可知、事件发生、结果首次可知；另存本系统首次看到的时间和交易假设首次登记的时间。改期、取消、议程变化记为新版本。只确认到日期的事件不能填分钟。
- **入库**（`backend/app/warehouse/calendar_events.py`）：种子导入时，首见时间就是导入时间，不倒填研究日期；重复导入不追加，内容有变才记新版本。股指期货 / 期权按第三个周五、ETF 期权按第四个周三推算，遇休市顺延；用交易所日历算出的 11-20 / 11-25、12-18 / 12-23 与种子一致，状态保持"规则推算，待当月通知"。
- **首个实证**（E052）：
  - PRE（32 个月）里没有周四效应；高换手高波动组最弱的是周五（−0.39%，t −2.34）。
  - DEV（4 个月、17 个周四）里周四明显偏弱（全部 −0.55%，下跌日 71%；高换手组 −1.07%，t −2.17）。
  - 交割日相对其他周五没有显著差异。
  - 结论：周四只作为条件特征进前向记录，不改变仓位。
- **下一步**：每周发现未来 90 天事件，每日核对未来 30 天日程；首页加"近期日程"一栏，优先显示与持仓和主题相关的事件；日历策略和消息策略共用一个账本，同一事件不重复买入。补充设计的 16 项实验编号为 `DC-E01`~`DC-E16`。
- **自动同步源（2026-11-02）**：东方财富数据中心「财经日历」（data.eastmoney.com/cjrl，接口 `RPT_CPH_FECALENDAR`，数据来自 Choice），`python -m backend.app.warehouse.calendar_events sync [天数]`。11-02 拉未来 90 天得到 796 个事件：经济数据 752（精确到分钟 621）、会议展会 22、海外政策 11 等；中国 106、美国 308。源里 00:00:00 表示只有日期，记成日期精度，不填分钟；同一发布在同一天列两个时间（12 个，如香港 GDP 14:30 / 16:30）的取较早者并标为近似分钟。重复同步无变化时不追加。缺口：没有交割日（继续按规则推算）、没有个股事件（股市日历 `RPT_SPECIAL_*` 另接）、FOMC 等海外议息只到 90 天内有登记的。文章《11月大事早知道》是图片加二维码，不能直接解析。
- **待核实**：11-02 为农历九月廿四，本地没有农历库，未核实。

## 5. 2026-11-02 收盘后拍板

- **分时抓取**：16:20 开始（在 Pulse 15:35 日线同步之后），每秒 1 次，只抓热点池 ∪ 涨跌 5% 以上 ∪ 当日涨停 / 炸板 / 跌停池 ∪ 当日出现过的消息联动股。顺序（保险 A，`intraday.minute_order`）：涨停 → 炸板 → 跌停 → 消息联动 → 其余；按 11-02 的池子，前约 160 只在 3 分钟内抓完。不再抓全市场分时。
- **快照合成 1 分钟线**（保险 B，`backend/app/warehouse/minute_synth.py`）：录制器每天收尾时用 60 秒全量快照和 10 秒热点快照为全部代码合成 `minute_synth.parquet`，K 线标签取分钟结束时刻，与腾讯一致。11-02 对照 307 只已抓到的腾讯分时：累计成交量差异在 0.5% 内的占 97.1%，在 2% 内的占 99.2%；VWAP 相对差中位数 1.8e-6，P95 4.0e-5；收盘价完全一致的占 69%（快照不在分钟末尾）。高低价是快照价，不是成交价。
- **11-02 盘后表回刷**：`intraday reparse` 用原始文本重建 `quotes.parquet` / `hot.parquet`，原表留作 `*.v0.parquet`。86.3 万 + 78.3 万行全部重建，价格逐行一致；15:30 有盘后成交 2,497 只，合计 6.20 亿元。亚振家居盘后 1.12 亿元，比它当天日内成交额 0.998 亿元还多。
- **M3 `catalyst_pending`**：事件进行中、结果未出时记为未知（`None`），不变。M3-Tape（未知不否决）与 M3-Strict 对比"会中是否持有到结果公布"。
- **E046**：大模型卡片特征锁定为"匿名 + 申万行业与题材拓扑"。依据是申万子集 IC +0.166（t 2.10）高于实名 +0.138；逐日配对差不显著，所以 OOS 继续记录实名版影子结果做对照。
- **E047**：不按 16 个主线标签挑因子，因子权重维持扩展窗口。
- **E048 / E049**：从 11-03 起前向记录 14:50 真实快照上的盘尾预警，规则是"今晚拉萨 ≥3 席 或 一日游席位 ≥2 席"，当晚用龙虎榜结果评分。注意：E048 里一日游席位 ≥2 极少出现（因此改用 ≥1），≥2 的分支预计很少触发，需要和 ≥1 并行记录。
- **E050**：缠论三买、下跌期 Spring 保留为日线结构特征；获利盘比例反号使用（防追高惩罚项）；单峰突破追涨淘汰。
- **新特征：盘后成交占比** = 盘后成交额（字段 58，万元 × 1e4）÷ 日内成交额。P1 起每日记录，重点看占比高的股票次日竞价与日内表现。
