# 第六批预注册：短线联动、席位、集合竞价、主动买卖（E093–E096，2026-11-18）

> 写于看到任何相关结果之前。第 1–6 节写定后不再修改；改阈值、改定义、改样本都算新实验（新编号），结果写在第 7 节。
> 来源：用户 2026-11-18 提出的四个问题：集合竞价（9:15 / 9:20 / 9:25）与隔夜单、主力和游资的进出、龙头对中军和跟风股的带动。
> 台账已有的相关结论：E027、E038 日线次日执行的龙头类策略全部失败（买不到能赚钱的票，买到的多是炸板）；E045 主线识别改进但仍亏；E048 拉萨席位之后 5~10 日稳定跑输（有效的风险信号）；E054 昨日涨停次日高开追买三年都为负，开盘卖在非冷状态更好；E072 隔夜外盘信息在竞价里已定价。

## 1. 共同规则

- **范围**：沪深主板（00、60 开头），剔除 ST、上市不满 60 个交易日、当日停牌。和以往批次一致，不含创业板、科创板、北交所。
- **成本**：往返 0.252%，所有收益扣费后报告。
- **基准**：E062 的同日匹配基准（同市值五分位 × 同波动五分位），以下"超额"都指相对它。
- **显著性**：E082 的块自助法，块长 = 持有天数（按交易日），单侧，10,000 次，固定种子 20261118。
- **分段**（与以往批次相同）：PRE = 2026-06-30 及以前，DEV = 2026-07-01 及以后。
- **多重检验**：本批共 7 条假设（H1–H7），用 Holm 校正，族内显著水平 0.05。
- **可成交**：
  - D+1 开盘买入：开盘价等于涨停价（含一字板、开盘封板）视为**买不到**，记为未成交，不计收益，单独报告成交率；
  - 卖出：开盘或收盘价等于跌停价视为卖不掉，顺延到下一个可卖时点；
  - 盘中买入（只在第 4–5 节）：用该分钟快照的卖一价成交，卖一量为 0 视为买不到。
- **只在通过后才改规则**：本批任何结果在判定通过之前，都不改变主书、影子账本或纸面回放的任何买卖规则。

## 2. E093：龙头对中军和跟风股的带动（历史回测，日线）

**题材口径**：申万二级行业，按带日期的成分（E045 的口径，无前视）。不用概念名单（E030 发现概念名单有前视）。

**每个行业每天的角色**（D 日收盘后确定）：
- **龙头**：D 日连板数最高且 ≥ 3 的成分股；并列时取 D 日成交额最大的；
- **中军**：除龙头外，D 日成交额最大、且流通市值不低于该行业成分中位数的成分股；
- **跟风**：除龙头外，D 日首板（连板数 = 1）的成分股。

**事件**：
- **断板**：前一交易日连板 ≥ 3 的龙头，D 日没有涨停收盘；
- **晋级**：龙头 D 日继续涨停，连板数达到 ≥ 4。

**假设**（D+1 开盘买入，持有到 D+3 收盘，每个事件对应的股票等权）：
- **H1（风险）**：断板事件之后，同行业的跟风股和中军的匹配超额 < 0。
- **H2（带动）**：晋级事件之后，中军的匹配超额 > 0。

**通过标准**（两条都要满足）：PRE 段方向正确、扣费后幅度超过 0.252%、Holm 校正后显著；DEV 段同号。H1 通过只作为**回避过滤**的候选，不产生买入信号。

**已知局限**：日线只能次日执行；龙头的认定用的是收盘后的连板数，盘中的分歧看不到。

## 3. E094：席位扩展（历史回测，龙虎榜）

**数据**：pulse3 导入的龙虎榜席位（约 3 年）。席位当晚公布，所以只能 D+1 开盘起执行。

**假设**（D+1 开盘买入，持有 5 个交易日）：
- **H3（行业层面风险）**：D 日某申万二级行业里，有成分股出现拉萨席位 ≥ 3 家（E048 的口径）。该行业其他成分股（不含上榜股）的匹配超额 < 0。
- **H4（机构席位）**："机构专用"席位合计净买入 > 0、且净买入额 ≥ 当日成交额的 5% 的上榜股，匹配超额 > 0。

**通过标准**：同第 2 节。

**已知局限**：龙虎榜只覆盖上榜股，"主力资金"里大部分看不到。东方财富的主力资金流（`intel fundflow`）从 2026-11-18 起才开始逐日记录，只覆盖关注股，没有历史，本批不检验它，只记录。

## 4. E095：集合竞价（前向，60 秒快照）

**数据**：服务器每分钟一次的全市场快照，覆盖 09:15–09:25（从约 2026-11-02 起）。前向记录从本文提交后的第一个交易日开始，此前的录制日只用来核对字段含义，不进评估。

**字段核对**（第一天完成，写进第 7 节，之后不改）：竞价期间买一量、卖一量、买二量各代表什么（已撮合量还是未撮合量）。如果某个字段的含义无法确认，依赖它的特征记为"无法计算"，不另换口径。

**每只股票每天的特征**：
- `gap_925`：09:25 撮合价相对昨收的涨跌幅；
- `gap_919`：09:19 末次快照的撮合价涨跌幅（09:20 之前可撤单）；
- `fade`：`gap_919 − gap_925`（撤单后的回落）；
- `amt_925_ratio`：09:25 撮合金额 / 前 20 日平均日成交额；
- `unmatched_buy`：09:25 未撮合的买量（字段核对通过才计算）。

**隔夜单**：公开数据看不到券商收到的隔夜委托。09:15 第一档的撮合量是它的近似，本批只记录，不作为假设。

**假设**（09:30 开盘价买入，当日收盘卖出；开盘封涨停的视为买不到）：
- **H5（真强势）**：`gap_925` 在 +2% ~ +7%，且 `amt_925_ratio` 在当日全市场前 20% 的股票，匹配超额 > 0。
- **H6（假强势）**：`gap_919` ≥ +5% 且 `fade` ≥ 3 个百分点的股票，匹配超额 < 0（回避信号）。

**判定**：攒满 40 个有信号的交易日（每条假设至少 25 天有信号）才判定；第 20 天只写描述，不判定。通过标准：扣费后方向正确，Holm 校正后显著。

## 5. E096：盘中主动买卖（前向，60 秒快照）

**特征**：用每分钟快照的外盘、内盘增量，算 09:30–10:00 的主动买入占比 `abr_30 = Δ外盘 / (Δ外盘 + Δ内盘)`。

**假设**：
- **H7**：10:00 时涨幅在 0 ~ +5%、`abr_30` 位于全市场前 10% 的股票，以 10:00 快照的卖一价买入、当日收盘卖出，匹配超额 > 0。

**判定**：同第 4 节（40 个交易日）。

**已知局限**：外盘、内盘是行情商按成交价相对买卖盘的推断，不是逐笔大单。"主力"无法从这里直接识别，本条只检验主动买入的不平衡。

### 7.2 竞价字段核对（E095，2026-11-19 完成，写入后不再改）

核对对象：服务器已导入的 2026-11-12、11-13、11-16、11-17、11-18 五个录制日（都早于前向起点 2026-11-19），命令 `python -m pulse.workers.batch6 fieldcheck`，结论存为数据集 `batch6_fieldcheck`，判据与阈值写在 `domain/batch6/auction.py::conclude`（共 239,224 个 09:15–09:24 带指示盘口的行，15,871 个 09:25 终盘行；另有 9,411 个行有价格但没有买一/卖一价，不算证据）。

- **09:15–09:24 的买一量 = 卖一量 = 当前虚拟撮合量（已撮合量，不是未撮合量）**：买一价 = 卖一价 = 撮合价的行占 99.48%，买一量 = 卖一量的行占 99.49%。旁证：撮合价没变时，09:25 的最终成交量不小于 09:24 的虚拟撮合量的占 99.25%（09:20 之后不能撤单，已撮合量只会增加；若是未撮合量则不会有这个规律），中位数为 2.39 倍（最后一分钟还有大量新单）。
- **买二量、卖二量 = 虚拟撮合后剩余的买盘 / 卖盘（未撮合量），两者互斥**：同时大于 0 的行只占 0.53%。
- **09:25 终盘（`auction_final`）的买卖盘 = 撮合后留在簿上的挂单，即未撮合**：`成交额 = 成交量 × 100 × 价` 的行占 99.67%，买一价 < 卖一价的行占 100%（没有交叉）。
- 结论：`unmatched_buy` 可以计算，定义为 09:25 终盘买一到买五的买量之和（手；只公布五档，所以是下限）。`matched_915`（09:15 第一档撮合量，隔夜单的近似）只记录。

核对过程的一次修正：第一版判据把"有价格但没有买一/卖一价"的行（没有交叉、没有虚拟撮合量）当成失败，买一价=撮合价的比例因此显示 95.7%、买一/卖一量的含义被判为"无法确定"。这是核对代码自己的错，不是数据的问题；在没有任何前向日之前改为"只统计带指示盘口的行"（`fieldcheck-v2`），旧版本留在数据集里。第一个前向日决定之后，核对结论不再替换。

### 7.3 实现中对预注册的字面解读与数据限制（不改第 1–6 节）

1. **日线窗口只有约 13 个月**：pulse3 的日线完整从 2025-10-31 起（再早只有零星代码）；前 10 个交易日作为连板数的预热期，所以决策日从 2025-11-14 起，PRE ≈ 2025-11-14 至 2026-06-30（约 7.5 个月），DEV = 2026-07-01 至 2026-11-18。龙虎榜席位虽有约 3 年，E094 只能用到与日线重叠的这一段。日线更长的导入完成后，`batch6 history` 可以直接重跑（结果是新的数据集版本，不是改这一节）。
2. **估计量**：日线没有成交额，成交额 = 收盘价 × 成交量（与 pulse3 市场状态一致，只用于排序和 H4 的 5% 比较）；pulse3 没有流通市值历史，流通市值 = 最近一份快照 ×（当日收盘 / 快照日收盘），即股本不变；ST 用当前的状态与名称；301 只没有上市日期的代码不在范围内。
3. **事件的龙头 L = 前一交易日的龙头**（连板数 ≥ 3）。断板：L 当日有行情且未涨停收盘；晋级：L 当日涨停收盘（连板数必然 ≥ 4）；L 当日无行情不算事件。当日的中军、跟风按 D 日数据确定，并排除 L 和 D 日自己的龙头（若不是 L）。中军的"流通市值不低于行业中位数"：中位数取该行业当日范围内、流通市值已知的成分股（偶数个取中间两个的平均），没有流通市值的股票不能当中军。断板事件买中军 + 全部首板跟风（H1 把两者合并检验），晋级事件只买中军（H2）。同一天同一只股票重复出现只算一次。
4. **范围**：沪深主板（00、60 开头）、非 ST、上市不少于 60 个交易日（上市日算第 1 个；早于日线窗口的用工作日近似）、当日有行情。
5. **超额与"扣费后幅度超过 0.252%"**：两边都付同样的往返费，所以匹配超额扣费前后相同；信号自己的收益单独报告扣费后的均值。"幅度超过 0.252%"取匹配超额的绝对值 > 0.252%（对正向假设等价于扣费后超额 > 0）。显著性只看 PRE 的单侧块自助法 p 经 Holm 校正后 < 0.05；同时要求块数 ≥ 10（E082：不足 10 块只报告、不采纳）。
6. **成交与卖出**：买入 D+1 开盘价，开盘价 ≥ 涨停价（上一收盘价 ×1.1 四舍五入到分，整数分计算）记为买不到；次日没有行情记为买不到（停牌）；到期收盘价 ≤ 跌停价则顺延到之后第一个"开盘或收盘价高于跌停价"的时点（最多 8 个交易日）。
7. **席位**：只用单日报告（窗口起止同为 D），同一股票同一日不同上榜原因的重复席位行按（买卖方向、席位名称、金额）去重；"拉萨"= 席位名称含"拉萨"（买方，按不同名称计数，≥ 3 家）；"机构专用"= 席位名称等于"机构专用"（名称里只是带有这几个字的券商营业部不算）。H3 的"上榜股"指当日有任何席位报告（含多日窗口）的股票，从行业成分里剔除。
8. **前向（H5、H6、H7）的字面解读**：`gap_919` 取 09:20:00 之前最后一个快照（`poll_at`）的价；`gap_925` 取 09:25:00–09:29:59 最后一个快照的价，需要撮合成交量 > 0；`amt_925_ratio` 的分母是前 20 个交易日"收盘价 × 成交量"的均值（至少 15 天）；"前 20% / 前 10%"= 当日有该指标的范围内股票里最高的 ⌈20%·N⌉ / ⌈10%·N⌉ 只（并列于分界线的一并计入）；H5 的 +2% ~ +7%、H7 的 0 ~ +5% 取闭区间，H6 的 3 个百分点取 `fade ≥ 0.03`；`abr_30` 用 09:30 之后第一个快照与 10:00 之后第一个快照（各自 3 分钟内）的外盘、内盘累计量之差；H7 以 10:00 快照的卖一价买入，卖一量为 0 记为买不到。E095、E096 的"当日收盘卖出"是同日测量腿（T+1 下并不能直接这样操作，需要有底仓，这一点在第 6 节"另行预注册可成交性检验"之前不作任何实盘解读）；收盘价等于跌停价卖不掉的，当日不计收益，由之后的 `resolution` 行按"顺延到下一个可卖时点"了结，不进当日超额。

#### 7.4.1 这次运行相对 7.1 的差别（含前复权涨停判定的已知偏差）

1. **涨停判定方式（融合线面板的定义）**：前复权价是浮点数、没有最小价位。涨停价 = round(前收 × 1.1, 2)，再留半分的容差（收盘 ≥ 涨停价 − 0.005 记为涨停；开盘同理为买不到；价格 ≤ 跌停价 + 0.005 记为卖不掉）。第一次运行用的是原始价的整数分精确计算。**两种判定在 2025-11 至 2026-11 的重叠窗口上并不一致**（本机对比，786,791 个股票日）：原始价判出 15,367 个涨停收盘，前复权判出 14,876 个，两者不一致 577 个，其中 534 个是前复权漏判（涨幅 9.85%–10.00% 的真涨停，因为复权价取到分后离真实涨停价差了不到一分而落在半分容差之外，例如 000029 2026-06-10 涨幅 9.9837%），43 个是前复权多判（其中 25 个发生在除权日）；连板数 ≥ 3 的股票日也从 1,151 减到 1,039（-10%）。所以**前复权运行系统性地漏掉约 3% 的涨停、约 10% 的 ≥3 连板日**，龙头、首板跟风、买不到的认定都会受到影响，但方向没有偏向某一假设。
2. **除权除息日**：原始价在除权日跳变——上一收盘价高于除权参考价，原始价算出的涨停价偏高，真实涨停被判成"没涨停"、真实跌停被判成"没跌停"，连板数被打断（第一次运行里这种日子只能靠 12.1% 的异常幅度护栏把无法判断的日子剔掉）。前复权的涨跌幅就是真实涨跌幅，除权日的涨停、连板数是对的（本机重叠窗口里，原始价因除权漏判、前复权判出涨停的有 25 个）。这是前复权价的优点，但被上一条的取整偏差抵消了一部分。
3. **成交额、流通市值**：前复权价乘以原始股数，早期日期的"成交额"带着该日的复权因子（多数股票偏差几个百分点，分红多的更大）；这会轻微影响中军的排序和 H4 的 5% 比较。流通市值仍按快照 ×（当日收盘 / 快照日收盘）估计，用前复权收盘比，已隐含分红再投资，拆股也不会跳变。
4. **范围、成交、卖出、Holm、种子、分段**与 7.3 完全相同；没有改任何阈值。内存：内存峰值约 1.8 GB（服务器预算 2.5 GB），为此把每个匹配池的基准均值算一次后只保留信号股票。
5. **没有做的事**：我没有用别的涨停判定重跑来"修"第 1 条的偏差（那会是对同一批数据的又一次多重查看，应另行预注册），只在这里如实记录。若要得到可靠的 H1 结论，需要一个不依赖复权价取整的涨停判定（例如原始日线更长的导入），再按新编号重跑。
