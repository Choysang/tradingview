# Pulse 3.0 外部项目评审与吸收对照

**核验日期：2026-10-30**
**范围：** 在 2026-10-20 评审（14 个项目，见 `2026-product-review.md`）之外，新增 11 个开源项目、4 个商业产品与社区资料。每一条都标注证据类型；没核实到的直接写“未核实”。

## 阅读口径

- **官方事实**：仓库源码、README、LICENSE、官方页面。
- **作者 / 社区观点**：单个作者或帖子的陈述，只当需求线索。
- **本项目决策**：吸收什么、放在哪、不吸收什么。

| 同花顺问财 iWencai | 一句话 → 结构化选股条件 | **问句选股**：确定性中文解析器（不调用 LLM），每个识别片段变成可单独移除的条件胶囊，未识别部分明示为“未识别”，不静默丢弃（`backend/app/query/nlq.py`，`POST /screener/parse`） |

## 三、社区资料

- **Reddit：未核实。** 本轮环境无法访问 reddit.com（搜索与抓取均被拦截），没有可引用的帖子 URL，不编造。上一轮评审中的 Reddit 线索仍然有效。
- 替代线索（厂商/作者观点）：[Tradomate](https://tradomate.one/blog/when-screener-backtests-mislead) 指出筛选器回测要用当时可得的信息（point-in-time）；[Trendlyne 帮助页](https://help.trendlyne.com/support/solutions/articles/84000346039-what-does-a-screener-backtest-involve-) 说明沿用当前成分会有幸存者偏差。→ Pulse 的形态与因子页面在 SIM 下明确标注“合成日线”，LIVE 下标注覆盖只数。
- **CSDN：只拿到搜索摘要，正文抓取返回 HTTP 521（未读正文）。** 摘要层面的共识：用 `stock_zt_pool_em` 做连板统计、情绪模块包含上涨比例 / 连板家数 / 压力高度、涨停质量按封单额 / 首封时间 / 换手 / 流通市值打分。这些与 Pulse 既有的封板质量因子与天梯一致；未采纳任何具体权重或胜率数字。

## 五、仍未覆盖

- Hikyuu 式的止损 / 止盈 / 资金管理组件；Kronos 概率走势面板。
- 形态与因子在 LIVE 下只扫描已缓存真实日线的标的（预热按成交额前 300 只），不是全市场。
- 问句解析器不支持“跌幅”“总市值”等少数说法，会进入“未识别”列表。
